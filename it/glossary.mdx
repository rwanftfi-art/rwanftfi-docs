Un'unica fonte di verità per i termini utilizzati in tutta la documentazione RWANFTFI.

| Termine | Definizione |
|---|---|
| **Saldo Cumulativo** | Saldo interno vincolato che riceve la quota configurata delle ricompense idonee dei partner. |
| **Auto-Sell** | Elaborazione programmata del DA residuo su quattro periodi di protocollo. |
| **Autobuy** | Rinnovo automatico di un NFT idoneo quando il suo Limite di Ricompense del Protocollo è esaurito. |
| **DA** | Token di utilità di protocollo non trasferibile, BEP-20, con un'offerta massima di 21.000.000 di unità. |
| **Frozen Balance** | Buffer temporaneo di 72 ore per uno Sponsor Bonus qualificante che supera il Limite di Ricompense del Protocollo residuo. |
| **GovToken** | Token di governance ERC20Votes a offerta fissa. |
| **Matching Bonus** | Ricompensa condizionale su un massimo di tre livelli qualificanti. |
| **Reddito Perso** | Attività non accreditata perché le condizioni di idoneità applicabili non sono state soddisfatte. |
| **NFTM** | Contatore interno di Mining utilizzato nel calcolo del Farming. |
| **Rete Partner** | Struttura gestita dallo smart contract, utilizzata per definire il posizionamento e l'idoneità alle ricompense. |
| **Profondità della Rete Partner** | Profondità massima di rete inclusa nei calcoli di distribuzione idonei. |
| **Limite di Ricompense del Protocollo** | Massimo cumulativo di ricompense idonee accreditate durante un ciclo NFT; termine on-chain: *Income Limit*. |
| **Sponsor Bonus** | Ricompensa condizionale da un acquisto NFT diretto qualificante. |
| **Tree Distribution** | Nome on-chain per la Distribuzione della Rete Partner — il calcolo della ricompensa di protocollo per livello entro la profondità di rete idonea. |
