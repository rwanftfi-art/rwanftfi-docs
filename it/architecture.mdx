RWANFTFI utilizza un'architettura Diamond [EIP-2535](https://eips.ethereum.org/EIPS/eip-2535) con sette faceti funzionali, contratti NFT e di riserva separati, meccanismi di aggiornabilità definiti, permessi basati sui ruoli e molteplici tipi di saldo interno.

## Faceti Diamond

| Facet | Funzione |
|---|---|
| AdminFacet | Ruoli, parametri, trasferimenti approvati e minting di NFT speciali. |
| MarketingFacet | Registrazione, acquisti NFT e calcolo delle ricompense dei partner. |
| FarmingFacet | Mining NFTM e Farming DA. |
| PaymentFacet | Depositi, prelievi, voucher e trasferimenti di saldo. |
| TreeFacet | Posizionamento e profondità della rete partner. |
| ResolverFacet | Valori scaduti, elaborazione dei voucher e risoluzione del Frozen Balance. |
| ViewFacet | Query di sola lettura su utenti, saldi e rete. |

## Contratti NFT

- Gli NFT Regular utilizzano ID token dispari.
- Gli NFT Gift utilizzano ID token pari.
- Gli NFT Ambassador utilizzano un contratto e una configurazione separati.

## Matrice di Aggiornabilità

| Componente | Modello |
|---|---|
| Diamond Contract | Aggiornabile tramite facet cut. |
| TokenReserve / DA | Aggiornabile tramite il meccanismo di proxy documentato. |
| Contratti NFT | Documentati come non aggiornabili. |
| GovToken | Documentato come non aggiornabile, con offerta fissa. |
| AdminContract | Documentato come non aggiornabile. |

## Gestione dei Ruoli

| Ruolo | Autorità Documentata |
|---|---|
| `ADMIN_ROLE` | Concede e revoca ruoli; modifica i parametri di protocollo consentiti. |
| `SERVICE_ROLE` | Esegue le operazioni di servizio automatizzate e cross-chain documentate. |
| `SIGNER_ROLE` | Verifica le firme autorizzate per azioni specifiche. |
| `MINTER_ROLE` | Minta il token o il tipo di NFT assegnato a quel ruolo. |

## Schema dei Saldi

| Saldo | Finalità |
|---|---|
| Saldo Regolare | Prelievi, acquisti e voucher idonei. |
| Saldo Cumulativo | Saldo interno vincolato, utilizzato secondo le regole documentate di acquisto, trasferimento, commissione e redistribuzione. |
| Limite di Ricompense del Protocollo | Idoneità residua alle ricompense per il ciclo NFT attivo; termine on-chain: *Income Limit*. |
| Saldo Riserva Token | Saldo del pool di liquidità designato a supporto della meccanica DA. |
| Saldo Dev | Allocazioni di protocollo e operative. |
| Saldo Price Impact | Riserva utilizzata dalle funzioni di price-impact documentate. |

## Priorità di Pagamento
