RWANFTFIのドキュメント全体で使用される用語の、単一の情報源です。

## プロトコル

| 用語 | 定義 |
|---|---|
| **アキュムレーティブバランス** | 適格なパートナー報酬のうち、設定された割合を受け取る制限付きの内部バランス。未使用の資金は、バランスのライフタイム（現在は180日で、DAO投票により暫定的に延長されています）の経過後に再分配の対象となります。 |
| **オートセル** | 残りのDAを、四つのプロトコル期間にわたって予定どおり処理すること。 |
| **Autobuy** | プロトコル報酬上限が使い切られたときに、適格なNFTを自動的に更新すること。 |
| **DA** | 21,000,000ユニットを最大供給量とする、転送不可のBEP-20プロトコルユーティリティトークン。 |
| **凍結バランス** | 残りのプロトコル報酬上限を超える、対象となるスポンサーボーナスのための一時的な72時間のバッファー。 |
| **GovToken** | 固定供給のERC20Votesガバナンストークン。 |
| **Income Limit** | プロトコル報酬上限のオンチェーン用語。 |
| **NFTM** | ファーミングの計算に使用される内部のマイニングカウンター。 |
| **フェーズ2** | 2026年6月にDAO投票によって有効化されたプロトコル構成：現在のNFT購入の分配と、Infinity（L10）の販売。 |
| **プロトコル報酬上限** | NFTサイクル中に計上される適格な報酬の累積最大額。オンチェーン用語：*Income Limit*。 |

## パートナープログラム

| 用語 | 定義 |
|---|---|
| **Business Sale** | DAOの承認により、パートナーストラクチャー全体を別のユーザーへ譲渡する機能。2026年6月からDAO投票により無効になっています。 |
| **ギフトNFT** | 購入も売却もできず、プロモーションやプログラムに基づいて付与されるNFT。独自のポジションとプロトコル報酬上限を持ち、その報酬は通常バランスとアキュムレーティブバランスに50/50で分割されます。ギフトNFTでFinFlowを利用することもできます。 |
| **マッチングボーナス** | 最大三つの対象階層にわたる条件付きの報酬。 |
| **逸失報酬** | 適用される適格性条件が満たされなかったために計上されなかった活動。 |
| **パートナーネットワーク** | 配置と報酬の適格性を定めるために使用される、スマートコントラクトで管理される構造。 |
| **パートナーネットワーク深度** | 適格な分配の計算に含まれる最大のネットワーク深度。 |
| **スポンサーボーナス** | 対象となる直接のNFT購入から生じる条件付きの報酬。 |
| **ツリー分配** | 適格なネットワーク深度の範囲内での、階層ごとのパートナー報酬の計算。 |

## FinPro

| 用語 | 定義 |
|---|---|
| **Claim Spot** | 参加者がストラクチャー内の枠を確保し、紹介リンクを受け取る、FinPro Marketingのローンチ前の段階。 |
| **Compound** | 計上額をポジションの元本に再投資すること。将来の計上額の絶対額が増加します。 |
| **Direct Sale** | FinPro Marketingにおいて、個人的に招待したパートナーのすべてのポジション計上額の5%。そのパートナーがどの階層に配置されていても適用されます。 |
| **Earn cap** | FinProのポジションの支払い上限。FinFlowでは当初の元本の200%で、元本を含みます。 |
| **FinCore** | 次のFinPro製品で、FinPro Marketingが適用される最初の製品。パラメータはローンチ前に公開されます。 |
| **FinFlow** | 2026年7月8日から稼働している最初のFinPro製品：マーケットニュートラル戦略のポジション。 |
| **FinFlow上限** | 一つのNFTで開設できるFinFlowポジションの合計の上限。基本上限はプロトコル報酬上限と同額です。 |
| **FinFlow NFT** | FinFlowポジションを表す譲渡不可のNFT。ポジションの開設は預金ではありません。 |
| **FinPro** | rwafinpro.comで提供されるエコシステムの金融製品ラインで、ユーザーのEVMウォレットから直接資金が拠出されます。 |
| **FinPro Marketing** | FinPro製品を対象とする独立したパートナープログラムで、独自のストラクチャーを持ちます：Direct Saleと20階層で、100%がマーケティング残高に計上されます。 |
| **ポジション計上額** | FinProのポジションで計上される金額。計上額は保証されません。 |
| **ポジション残高** | 追加入金と再投資額を含む、開設中のすべてのFinProポジションの合計。FinPro Marketingの階層を開放します。 |
| **Refund** | FinFlowの場合：保有者が当初の金額の50%を受け取って出金した後、ポジションをクローズし、当初の金額の100%までの残額の返還を受けることができます。 |

## セキュリティとサービス

| 用語 | 定義 |
|---|---|
| **AML Checker** | アプリケーションで利用できる、ウォレットアドレスの有料リスクチェック。19のブロックチェーンと14のステーブルコインが対象です。 |
| **ブリッジ** | bridge.rwanftfi.comで提供される、14のネットワークに対応したマネージド型のクロスチェーン入金サービス。 |
| **Secret Code** | 財務パスワードと一緒に生成されるランダムな単語。サポートへのセキュリティ関連のすべての依頼に必要です。 |
