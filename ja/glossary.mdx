RWANFTFIドキュメント全体で使用される用語の単一の情報源です。

| 用語 | 定義 |
|---|---|
| **アキュムレーティブバランス** | 対象となるパートナー報酬のうち、設定された取り分を受け取る制限付きの内部残高です。 |
| **Auto-Sell** | 残存DAを、プロトコルの4つの期間にわたって予定通り処理することです。 |
| **Autobuy** | 対象NFTのプロトコル報酬上限が枯渇した際に行われる自動更新です。 |
| **DA** | 最大供給量2,100万ユニットの、譲渡不可なBEP-20プロトコルユーティリティトークンです。 |
| **Frozen Balance** | 残りプロトコル報酬上限を超える、対象となるスポンサーボーナスのための一時的な72時間のバッファーです。 |
| **GovToken** | 固定供給量のERC20Votesガバナンストークンです。 |
| **Matching Bonus** | 最大3つの対象レベルにわたる条件付き報酬です。 |
| **ロストインカム(Missed Reward)** | 該当する資格条件が満たされなかったために計上されなかった活動です。 |
| **NFTM** | ファーミングの計算で使用される、内部的なマイニングカウンターです。 |
| **パートナーネットワーク** | 配置と報酬資格を規定するために使用される、スマートコントラクトが管理する構造です。 |
| **パートナーネットワーク深度** | 対象となる分配計算に含まれる最大のネットワーク深度です。 |
| **プロトコル報酬上限** | NFTサイクル中に計上され得る対象報酬の累計上限です。オンチェーン用語:*Income Limit*。 |
| **スポンサーボーナス** | 対象となる直接のNFT購入から生じる条件付き報酬です。 |
| **ツリー分配** | パートナーネットワーク分配のオンチェーン名です — 対象ネットワーク深度内でのレベルごとのプロトコル報酬計算を指します。 |
