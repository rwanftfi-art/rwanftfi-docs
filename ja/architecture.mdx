## Diamondファセット

| ファセット | 機能 |
|---|---|
| AdminFacet | ウォレットの変更とアカウントの制限、特殊NFTのミント、自動化されたサービス操作。 |
| ParametersFacet | プロトコルパラメータ、NFT設定、ギフトNFTのタイプ、機能の切り替え、ファーミング期間、手数料の範囲。 |
| MarketingFacet | 登録、NFT購入、パートナー報酬の計算。 |
| FarmingFacet | NFTMマイニングとDAファーミング。 |
| PaymentFacet | 入金、出金、バウチャー、残高の転送。 |
| TreeFacet | パートナーネットワークの配置と深度。 |
| ResolverFacet | 期限切れの値、バウチャーの処理、凍結バランスの解決。 |
| ViewFacet | ユーザー、残高、ネットワークに関する読み取り専用のクエリ。 |

Diamondには、EIP-2535の標準ファセットも含まれています：アップグレード用のDiamondCutFacet、イントロスペクション用のDiamondLoupeFacet、そしてOwnershipFacetです。

## NFTコントラクト

- 通常NFTは奇数のトークンIDを使用します。
- ギフトNFTは偶数のトークンIDを使用します。
- アンバサダーNFTは、独立したコントラクトと構成を使用します。

## アップグレード可能性マトリックス

| コンポーネント | モデル |
|---|---|
| Diamondコントラクト | ファセットカットによりアップグレード可能。 |
| TokenReserve / DA | 文書化されたプロキシメカニズムによりアップグレード可能。 |
| NFTコントラクト | アップグレード不可と文書化されています。 |
| GovToken | アップグレード不可かつ固定供給と文書化されています。 |
| AdminContract | アップグレード不可と文書化されています。 |

## ロール管理

| ロール | 文書化された権限 |
|---|---|
| DAOコントラクト | オンチェーンの範囲内でのパラメータ更新の適用、NFT設定の変更、機能の有効化と無効化、ファーミング期間と手数料範囲の設定、ウォレット変更の承認、アカウントの制限と復元。 |
| `ADMIN_ROLE` | ロールの付与と取り消し、ギフトNFTとアンバサダーNFTのミントおよびギフトNFTのタイプの管理、範囲内での取引手数料の設定。 |
| `SERVICE_ROLE` | 文書化された自動化サービス操作とクロスチェーンサービス操作の実行。 |
| `SIGNER_ROLE` | 指定されたアクションに対する承認済み署名の検証。 |
| `MINTER_ROLE` | そのロールに割り当てられたトークンまたはNFTタイプのミント。 |
| Diamondの所有者 | `diamondCut`によるファセットのアップグレードと、所有権の移転。 |

各ロールの関数レベルの一覧は、[CertiKレポート](/ja/security)の中央集権化に関するセクションに記載されています。

## バランススキーマ

| バランス | 目的 |
|---|---|
| 通常バランス | 適格な出金、購入、バウチャー。 |
| アキュムレーティブバランス | 文書化された購入、転送、手数料、再分配のルールに基づいて使用される、制限付きの内部バランス。タイマーのリセットに関する修正の準備が進む間、ライフタイムは暫定的に180日です。[コントラクトパラメータ](/ja/contract-parameters)をご覧ください。 |
| プロトコル報酬上限 | アクティブなNFTサイクルにおける残りの報酬適格性。オンチェーン用語：*Income Limit*。 |
| Token Reserveバランス | DAメカニクスを支える、指定された流動性プールの残高。 |
| デベロッパーバランス | プロトコルと運営のための配分。 |
| プライスインパクトバランス | 文書化されたプライスインパクト機能で使用される準備金。 |

<Note>
  **FinProのバランスは独立しています**。FinProのポジションは、ユーザーのEVMウォレットからUSDT（BEP-20）で直接開設され、支払いも同じウォレットへ行われます。通常バランスやアキュムレーティブバランスは使用されません。[FinProとFinFlow](/ja/finpro-finflow)をご覧ください。
</Note>

## 支払い優先順位

<Steps>
  <Step title="選択された有効なバウチャー">
    ユーザーがチェックアウト時に有効なバウチャーを明示的に適用した場合、その価値が最初に消費されます。
  </Step>
  <Step title="アキュムレーティブバランス">
    適格かつ選択されている場合に、文書化された手数料ルールに基づいて適用されます。
  </Step>
  <Step title="通常バランス">
    残りの金額は通常バランスから差し引かれます。
  </Step>
</Steps>

<Note>
  [BNB Smart Chain](https://www.bnbchain.org/en/bnb-smart-chain)上のすべての取引には、エコシステム内で使用される[USDT](https://tether.to/)残高とは別に、**BNB**で支払われる標準的なネットワークガス手数料が必要です。コントラクトのデプロイと残高は、[BscScan](https://bscscan.com/)で公開検証可能です。公式のコントラクトアドレスは、[app.rwanftfi.com/smart-contracts](https://app.rwanftfi.com/smart-contracts)に掲載されています。
</Note>
