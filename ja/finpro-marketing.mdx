## FinPro MarketingはRWAパートナープログラムとどのように異なりますか？

| | RWAパートナープログラム | FinPro Marketing |
|---|---|---|
| 報酬の源泉 | パートナーネットワーク内のNFT購入 | FinPro製品におけるパートナーの**ポジション計上額** |
| ストラクチャー | RWAパートナーネットワーク | **独立した**FinProストラクチャー。RWAのスポンサーは引き継がれません |
| 参加方法 | RWAメンバーの紹介リンク | **FinPro Marketing**メンバーのリンクまたはコードのみ |
| 深度 | NFTティアによる | 最大**20階層**。ポジション残高に応じて開放 |
| 報酬の配分 | 75 / 20 / 5と5%のPartner Reward Fee | マーケティング残高へ**100%**：75 / 20 / 5の配分も手数料もなし |
| 共有の上限 | メインNFTのプロトコル報酬上限 | 同じプロトコル報酬上限を両プログラムで消費 |

FinPro Marketingのローンチに伴ってRWAパートナープログラムが変更されることはありません。

## Claim Spot

**ローンチ前の条件**：

- **メインNFT**：参加者のRWANFTFIのメインNFTが本人のウォレット内にあること。
- **FinFlowポジション**：**500 USDT**以上、またはメインNFTにおける参加者の報酬総額の10%以上のうち、いずれか高い方。すでに開設済みのポジションも対象となります。

<Steps>
  <Step title="ウォレットを接続する">
    RWANFTFIのNFTを保有しているウォレットを接続します。
  </Step>
  <Step title="FinFlowポジションを開設または利用する">
    500 USDTからFinFlowポジションを開設するか、既存のポジションを利用します。
  </Step>
  <Step title="Claim Spotを押す">
    FinPro Marketingメンバーの紹介リンクまたはコードを通じて、**Claim Spot**を押します。
  </Step>
</Steps>

**参加者が受け取るもの**：

- FinProストラクチャー内の枠：**恒久的**で、後にすべてのポジションがクローズされても維持されます。
- 紹介リンク：Claim Spotの直後に発行されます。
- 早期アクセス：FinCoreのローンチ前からパートナーネットワークを構築できます。

ストラクチャー内の枠は、参加のタイミングによって決まります：参加者とそのパートナーが早く枠を確保するほど、より上位に配置されます。FinCoreのローンチ前に構築されたストラクチャーは、マーケティング報酬の計上初日から対象となります。

<Warning>
  制裁リストに掲載されているアドレスは参加できません（AMLスクリーニング）。ローンチ前の条件は一時的なものであり、FinCoreのローンチ時に標準の参加ルールに置き換えられます。
</Warning>

- 各参加者の直下には**二つの枠**があります。参加者が二人を超えて招待した場合、それ以降の人は、その参加者のストラクチャー内のより深い位置に配置されます（スピルオーバー）。

## マーケティング報酬はどのように計算されますか？

**源泉**。マーケティング報酬は、マーケティングが有効なFinPro製品でパートナーが受け取る**ポジション計上額**から計算されます。その最初の製品がFinCoreです。パートナーがポジションに拠出した金額から計算されることはなく、**マーケティング報酬に対するマーケティング報酬はありません**：パートナー自身のマーケティング報酬が、その上位の参加者のマーケティング報酬を生み出すことはありません。

**頻度**。一日一回、ポジション計上額と同時に計上されます。履歴では、独立した記録タイプ*FinPro income*として表示されます。

| 報酬 | 支払先 | 金額 |
|---|---|---|
| **Direct Sale** | パートナーを個人的に招待した参加者（パートナーがどの階層に配置されていても） | そのパートナーのすべてのポジション計上額の**5%**（無期限） |
| **階層別料率** | パートナーより上位のすべての参加者（階層1から階層20まで） | 階層に応じて0–3%（下表を参照） |

個人的に招待したパートナーがスピルオーバーによって階層2またはそれより深い階層に配置された場合、招待した参加者はDirect Saleの5%とその階層の料率の**両方**を受け取ります。

| 階層 | 料率 |
|:---:|:---:|
| Direct Sale | 5% |
| 1 | 0% |
| 2 | 1% |
| 3–10 | 各2% |
| 11–15 | 各3% |
| 16–17 | 各2% |
| 18 | 1% |
| 19–20 | 各0.5% |
| **合計** | **最大43%** |

これらはローンチ時の値です。変更の可能性については、後述の*ルールと保護*をご覧ください。

> **例**。パートナーが200 USDTのポジション計上額を受け取ります。参加者はそのパートナーを個人的に招待しており、パートナーは参加者の階層3に位置しています。Direct Sale 5% = 10 USDT、階層3の2% = 4 USDTで、この計上分からの合計は**14 USDT**です。そのパートナーの以降のすべての計上額からも、同じ割合を受け取ります。

## 開放階層とポジション残高

参加者のパートナーネットワークは全20階層でマーケティング報酬を生み出しますが、参加者が受け取るのは**開放されている階層からの分のみ**です。

- **ポジション残高が階層を開放します**。ポジション残高とは、FinFlowを含むすべてのFinPro製品で開設中のすべてのポジションの合計で、追加入金と再投資額を含みます。クローズされたポジションは含まれません。
- 残高が大きいほど、より多くの階層が開放されます（最大20）。階層ごとの閾値は公開されていません。
- **毎日判定されます**。残高が増えると、次回の計上から追加の階層が適用されます。ポジションがクローズされて残高が減少すると、開放階層の数が再計算されます。
- **閉じている階層は、マーケティング報酬の逸失を意味します**。

> **例：20階層中8階層が開放されている場合**。参加者は、階層1–8（13%）にDirect Sale（5%）を加えた **18%** を受け取ります。階層9–20の25%は逸失となります。より多くの階層を開放するには、ポジションへの資金の追加、マーケティング報酬の再投資、またはCompoundの有効化を行ってください。

## 二つの上限

マーケティング報酬の計上はいずれも、**両方**の上限を同時に消費します。

| 上限 | 内容 | 消費するもの |
|---|---|---|
| **プロトコル報酬上限**（オンチェーン：*Income Limit*） | 参加者のRWANFTFIのメインNFTの上限 | RWAのパートナー報酬**と**FinPro Marketingの両方。上限は共有されます。FinProのポジション計上額はこの上限を消費**しません**。 |
| **Earn cap** | FinPro製品におけるポジションの支払い上限 | ポジション計上額とマーケティング報酬の両方 |

> **例**。40 USDTのマーケティング報酬が計上されます。プロトコル報酬上限：2,000 → 1,960。ポジションのEarn cap：上限までの残りが1,600 → 1,560。

**状態**：

- **上限の残りが計上額より少ない場合**。残りの上限の範囲内の金額が計上されます。例：上限の残りが30 USDTで計上額が50 USDTの場合、計上されるのは30 USDTです。
- **プロトコル報酬上限 = 0**。FinProとRWAのすべてのマーケティング報酬は、NFTが更新またはアップグレードされるまで停止します。FinProのポジション計上額は継続します。FinProのマーケティング報酬によってAutobuyが作動することは**ありません**：保有者が手動でNFTを更新またはアップグレードします。
- **Earn capに到達した場合**。ポジションは完了し、計上が停止します。ポジション残高と開放階層は再計算されます。

**マーケティング報酬によるEarn capの消費順序**：開設日の古いポジションから順に消費されます（通常はFinFlowポジション）。階層を失わないよう、ポジションに追加入金するか、Compoundを有効にしてください。

**元本の返還**。元本返還のない製品では、ポジションのクローズ後に元本は返還されません。元本返還のある製品では、ロック期間がある場合はその終了後に返還されます。

## Earn capとマーケティング参加者ボーナス

マーケティングが有効な製品では、ポジションの上限は二つの層で構成されます。正確な値は、各製品のローンチ前に公開されます。

| 層 | 満たすもの |
|---|---|
| メインの上限 | ポジション計上額とマーケティング報酬 |
| マーケティング参加者ボーナス | **マーケティング報酬のみ** |

- ボーナスは、**最初のマーケティング報酬の計上**（いずれかのパートナーからの少なくとも一件の報酬）によって解放されます。このステータスは恒久的で、開設中のすべてのポジションに適用されます。
- マーケティング報酬は、まずボーナス層を満たし、その後メインの上限を満たします。
- ボーナス層がまだ満たされていない間にポジション計上額がメインの上限に達した場合、そのポジションの計上は停止します。ポジションは合計の上限に達するまでマーケティング報酬のために開設されたままとなり、引き続き開放階層の算定に含まれます。

## 圧縮

パートナーより上位の参加者が非アクティブな場合でも、その階層の分は失われません：その割合は、さらに上位の次のアクティブな参加者へ渡され、同様にチェーンを上っていきます。

上位の参加者は、次の場合にスキップされます（圧縮）：

- メインNFTのプロトコル報酬上限が0の場合
- NFT上限に関するスマートコントラクト上の同意がない場合
- ブロックされている場合、または制裁リストに掲載されている場合

非アクティブな参加者は、その期間中、自身のパートナーネットワークからのマーケティング報酬を逸失します。上限を使い切る前に、NFTを更新またはアップグレードしてください。

## NFT上限に関するスマートコントラクト上の同意

- **内容**。FinPro Marketingが自身のメインNFTの上限を消費することについての、参加者による確認です。これにより、FinPro MarketingとRWAパートナープログラムが一つのプロトコル報酬上限を共有できます。
- **時期**。最初のマーケティング報酬の計上前です。参加者は自身のウォレットから確認します。
- **取り消し可能**。取り消し後は、FinPro Marketingの報酬がその参加者に計上されなくなり、圧縮によってスキップされます。
- **透明性**。上限からの差し引きはすべて、FinProコントラクトにおけるマーケティング報酬の計上とともにオンチェーンで記録されます。
- **行われないこと**。新しいトークンは発行されず、メインコントラクトをUSDTが経由することもありません。
- **債務なし**。日次計算の後、その日のうちに上限が尽きた場合は、残りの上限の範囲内の金額が計上されます（または何も計上されません）。事後の追加支払いや債務は発生しません。

## マーケティング残高：再投資、Compound、出金

マーケティング報酬は、それを受け取った製品内で保持されます：FinCoreのマーケティング報酬はFinCore内に、他の製品も同様です。資金が製品間で移動することはありません。

<Tabs>
  <Tab title="再投資">
    同じ製品内の、最も新しい開設中のポジションにのみ再投資できます。開設中のポジションがない場合は新たに作成され、以降の再投資によってそのポジションが増加します。ポジションにはウォレットから追加入金することもできます。再投資はポジション残高を増やし、階層を開放します。
  </Tab>
  <Tab title="Compound">
    - **オン**。その製品の未出金のマーケティング残高の全額が直ちにポジションに投入され、その製品における新たなマーケティング報酬の計上額の100%が自動的にCompoundされます。
    - **オフ**。計上額は残高に蓄積され、いつでも出金できます。すでに再投資された金額はポジションに残ります。
    - Compoundは常に **100%** です。部分的なCompound（例：30%）は利用できません。残高の一部を残すには、先にその分を出金してから、Compoundを有効にしてください。有効にする前に、インターフェースに次の趣旨の警告が表示されます：*Xの残高が再投資されます。残高を残すには、先に出金してください。*
    - すでにClaimに送られた金額は、Compoundの対象になりません。
    - 製品にロック期間がある場合、ロック期間は再投資ごとに個別に適用されます。
    - ポジション計上額のCompoundは、各製品独自のルールに従います。
  </Tab>
  <Tab title="出金">
    すべての製品のマーケティング報酬は**一つの共通Claim**に送られ、一回の操作でウォレットへ出金されます。

    - **受け取り期限は365日**。365日以内に受け取られなかったマーケティング報酬は、DA流動性プールへ振り向けられます。
    - **マーケティング報酬の100%が参加者のものです**。75 / 20 / 5の配分もPartner Reward Feeもありません。
  </Tab>
</Tabs>

## 一つのストラクチャー、すべての製品

- 一つのFinProストラクチャーが、すべてのFinPro製品にわたって機能します。
- 複数の製品に参加するパートナーからは、それぞれの製品のマーケティング報酬がもたらされます。
- ストラクチャーは階層ごとに倍増します：2、4、8、16、32、64 … と続き、階層20では、1,048,576枠に達します。
- したがって、参加者のマーケティング報酬は三つの要素によって決まります：自身のパートナーネットワーク、開放階層の数、パートナーが参加している製品の数です。

## ルールと保護

| ルール | 現行のドキュメント |
|---|---|
| 恒久的な枠 | すべてのポジションがクローズされた後も維持されます。 |
| 招待のみ | FinPro Marketingメンバーのリンクまたは紹介コードを通じて参加します。RWAのスポンサーが自動的に割り当てられることはありません。 |
| DAOを通じたウォレットの変更 | 枠、ポジション、残高、保留中のClaimリクエスト、上限に関する同意が新しいウォレットへ移されます。 |
| FinProは売却不可 | FinProではBusiness Saleが無効です：ストラクチャーとポジションは保有者のウォレットに残ります。 |
| パラメータの変更はマルチシグ経由のみ | Direct Saleと階層別料率、階層の数、上限、ボーナスは、マルチシグのトランザクションによってのみ変更されます。変更履歴はオンチェーンで確認できます。 |
| 上限の変更 | 開設中のものを含むすべてのポジションに適用されます。新しい上限がすでに受け取った金額を下回る場合、ポジションはクローズされます。超過支払分の返還は求められません。 |
| Claimコントラクト | 資金の裏付けがある出金リクエストのみを保持します。バックエンドは資金にアクセスできません。 |
| 上限の透明性 | NFT上限からの差し引きはすべて、マーケティング報酬の計上とともにオンチェーンで記録されます。 |

## マーケティング報酬が計上されない場合があるのはなぜですか？

- その階層が参加者に対して開放されていません。
- メインNFTのプロトコル報酬上限がゼロです。
- 上限に関する同意が確認されていません。
- すべてのポジションのEarn capが満たされているか、開設中のポジションがありません。
- パートナーが、マーケティングのない製品（FinFlow）で計上額を受け取っています。
