> ***「信頼は約束ではない — それはパラメータであり、監査されたスマートコントラクトにハードコードされている。」***
>
> **— RWANFTFI**

RWANFTFIエコシステム内のすべてのパラメータはスマートコントラクトによって定義され強制されます。各パラメータはオンチェーンで公開検証可能です。一部のパラメータは事前定義された安全範囲内でDAOガバナンスにより調整可能です。残りのパラメータは恒久的にハードコードされており、開発者を含む誰も変更することはできません。

## 手数料とコミッション

すべての手数料はスマートコントラクトにより強制され、DAOガバナンスを通じて定義された範囲内で調整可能です。

| パラメータ | 現在 | 範囲 |
|---|---|---|
| マーケティング報酬税 | 5% | 5%~15% |
| アキュムレーティブ転送手数料 | 20% | 10%~30% |
| アキュムレーティブ使用手数料(NFT購入) | 20% | 10%~30% |
| ローン手数料 | 5% | 0%~5% |
| 引出手数料 | 0% | 0%~5% |
| ギフト送信価格 | $0 | $0~$25 |
| ビジネス売却手数料 | $500 | $0~$500 |
| 凍結バランス → スポンサー | 30% | 0%~30% |

<Note>
  **ローン手数料 - セマンティクス:** 5%は**ローン発行時に一度だけ**徴収され、DA流動性プールへ直接振り向けられます。全額または部分返済時に手数料は再度発生しません。このパラメータは、DAOがマーケティング税、アキュムレーティブ手数料、その他の手数料に影響を与えることなくレンディングの経済性を独立して調整できるよう、専用の`loanFee`としてオンチェーンに格納されており、プロトコルの他の手数料パラメータとは分離されています。
</Note>

<Note>
  **ビジネス売却手数料 — セマンティクス:** 「ビジネス売却手数料」の行は、ビジネスストラクチャー転送を実行するために**売り手が支払う転送手数料**です。買い手から徴収される販売価格では**ありません** — 買い手はプロトコルへのオンチェーン手数料を支払わず、執行時にパートナーツリー構造を受け取ります。この手数料を統治するオンチェーンパラメータは`businessTransferFee`です(本来の手数料セマンティクスを反映するため、レガシーの`businessSalePrice`からリネーム)。
</Note>

### オートセル期間

オートセルサイクルは、ユーザーが手動売却しない場合、残りのDA残高から段階的にトリガーされます。総サイクル時間は4期間すべての合計です。

| 期間 | 現在 | 範囲 |
|---|---|---|
| 期間1 | 120日 | 60~120日 |
| 期間2 | 90日 | 60~120日 |
| 期間3 | 90日 | 60~120日 |
| 期間4 | 65日 | 60~120日 |
| **総サイクル** | **365日** | — |

</Note>

| パラメータ | 値 |
|---|---|

| オートセル / レンディング支払 | 70% |
| LTV比率 | 70%(固定) |
| 階層あたりマッチングボーナス | 5% |
| 凍結バランスウィンドウ | 72時間 |
| バウチャーライフタイム | 365日 |
| バウチャー転送ロック | 最終1日 |
| ローン適格性閾値 | 30日 |
| DAO非アクティブ閾値 | 31日 |
| DAO猶予期間 | 7日 |

<Note>
  **ローン適格性閾値 - セマンティクス:** これはローンの期間では**ありません**。これは**すべての新規`loan()`呼び出しの前に実行されるローリングオンチェーンチェック**です(`_getTimeToNextAutosale(stack) >= 30 days`):担保に入れられるDAバッチは、次のスケジュールされたオートセルトリガーまで少なくとも30日間残っている必要があります。そうでなければ呼び出しは取り消されます。次のトリガーまで29日以下のバッチは新規ローンの担保として使用できません。

  これは商品へのアクセスを制御する**適格性ゲート**であり、オープンなローンの生涯を制御する**ローン期間**ではありません。ローンが開設された後、借り手はバッチが最初のオートセルトリガーを超えていない限り、全額または部分的にいつでも`repay()`を呼び出せます。そのトリガー後も`repay()`は呼び出し可能ですが、コントラクトはまず`_processExpiredStacks()`を実行して経過したすべての期間境界を清算してから、バーン後の残りに対して返済が進みます。
</Note>
