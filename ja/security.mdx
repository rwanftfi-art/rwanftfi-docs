## 監査の詳細

| 項目 | 確認先 |
|---|---|
| 監査人 | CertiK |
| レポートの日付 | 2026年4月28日 |
| 監査対象のコミット | 正確なハッシュは公開レポートに記載されています。 |
| 対象コントラクト | レビューされたすべてのコントラクトは、公開レポートに記載されています。 |
| 指摘事項 | ID、重大度、ステータスは公開レポートに記載されています。 |
| 修正 | 解決済みの各指摘事項は、レポート内で対応するコード変更に紐づけられています。 |
| デプロイメントの対応関係 | 現在の本番コントラクトが監査済みバージョンと一致するかどうかは、別途公開されます。 |
| バグバウンティ | 外部から検証可能な現在のステータスは、公式チャネルで公開されます。 |
