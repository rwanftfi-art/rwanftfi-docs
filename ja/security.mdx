## アカウント保護

監査はオンチェーンスマートコントラクトレイヤーをカバーしています。アプリケーションレイヤーでは、ユーザーアカウントはさらに複数の独立したメカニズムによって保護されています。

<CardGroup cols={2}>
  <Card title="3レベルセキュリティ" icon="layer-group">
    ログイン、財務アクション、高価値操作を分離する階層型保護。
  </Card>
  <Card title="TANコード" icon="key">
    すべての金融取引に必要な単回使用のトランザクション認証番号。
  </Card>
  <Card title="財務パスワード" icon="fingerprint">
    ログイン認証情報とは別のパスワードで、資金を移動する場合のみ必要。
  </Card>
  <Card title="2FA + Telegramボット" icon="telegram">
    標準的な二要素認証に加え、公式Telegramボットを通じたアクション検証。
  </Card>
</CardGroup>

<Info>
  **取引にはWeb3ウォレットが必要です。** メールとパスワードでダッシュボードにサインインしてデータを表示することはできますが、任意の金融アクションを実行するには接続されたWeb3ウォレット(MetaMask、Trust Wallet、または他のEVM互換ウォレット)が必要です。
</Info>
