対象となるプレミアムおよびエリートNFT保有者は、完全な対象DAバッチを担保として、USDT建てローンを利用できます。

## ローンパラメータ

| パラメータ | 現行ルール |
|---|---|
| 対象ティア | L5~L10 |
| 担保 | 完全なDAバッチ1つ |
| LTV | 70% |
| 発行手数料 | 5% |
| 債務基準 | ローン発行時に記録されたDAプロトコル価格 |
| 新規ローンの適格性 | 次回のAuto-Sellイベントまで少なくとも30日 |
| バッチの再利用 | バッチあたり1ローン |
| 返済 | 全額または部分返済 |

## ローンはどのように計算されますか?

総ローン額 = 担保DA × 記録されたローン価格 × 70%。

発行時に現行の5%手数料が差し引かれます。残額は、有効な残高ルールの下で計上されます。

## 価格スナップショット

記録されたローン価格は、返済計算の基準値として維持されます。その後のDAプロトコル価格の変動は、当初のUSDT建て元本を変更しません。

## 部分返済

借り手は未返済元本の一部を返済し、比例した分の残存担保を解放することができます。解放されたDAは、元のバッチのスケジュールの対象であり続けます。

## デフォルトと段階的な担保処理

バッチがAuto-Sellに入った時点でローンが未決済のままの場合、担保に入れられたDAは標準スケジュールに従って段階的に処理されます。借り手は各期間の境界の間に返済を行い、まだ処理されていない担保を解放することができます。

## 重要なレンディング条件

<Warning>
  - DAバッチは一度しか担保に入れることができません。
  - ローンは現行の適格性期限より前に開設する必要があります。
  - 元のAuto-Sellスケジュールはリセットされません。
  - デフォルト処理の影響を受けるのは、担保に入れられたバッチのみです。
</Warning>
