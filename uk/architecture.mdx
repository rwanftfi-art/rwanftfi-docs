RWANFTFI використовує архітектуру Diamond ([EIP-2535](https://eips.ethereum.org/EIPS/eip-2535)) із сімома функціональними фасетами, окремими контрактами NFT і резерву, визначеними механізмами оновлюваності, рольовими правами доступу та кількома типами внутрішніх балансів.

## Фасети Diamond

| Фасет | Функція |
|---|---|
| AdminFacet | Ролі, параметри, схвалені перекази та мінт спеціальних NFT. |
| MarketingFacet | Реєстрація, купівлі NFT та розрахунки партнерських винагород. |
| FarmingFacet | Майнінг NFTM та Фармінг DA. |
| PaymentFacet | Депозити, виведення коштів, ваучери та перекази балансів. |
| TreeFacet | Розміщення та глибина партнерської мережі. |
| ResolverFacet | Прострочені значення, обробка ваучерів та розв'язання Frozen Balance. |
| ViewFacet | Read-only запити щодо користувачів, балансів і мережі. |

## Контракти NFT

- Звичайні NFT використовують непарні token ID.
- Подарункові NFT використовують парні token ID.
- Ambassador NFT використовують окремий контракт і конфігурацію.

## Матриця оновлюваності

| Компонент | Модель |
|---|---|
| Контракт Diamond | Оновлюється через facet cuts. |
| TokenReserve / DA | Оновлюється через задокументований проксі-механізм. |
| Контракти NFT | Задокументовані як необновлювані. |
| GovToken | Задокументований як необновлюваний, з фіксованою емісією. |
| AdminContract | Задокументований як необновлюваний. |

## Управління ролями

| Роль | Задокументовані повноваження |
|---|---|
| `ADMIN_ROLE` | Надання та відкликання ролей; зміна дозволених параметрів протоколу. |
| `SERVICE_ROLE` | Виконання задокументованих автоматизованих і крос-чейн сервісних операцій. |
| `SIGNER_ROLE` | Перевірка авторизованих підписів для вказаних дій. |
| `MINTER_ROLE` | Мінт токена або типу NFT, закріпленого за цією роллю. |

## Схема балансів

| Баланс | Призначення |
|---|---|
| Звичайний баланс | Дозволені виведення коштів, покупки та ваучери. |
| Накопичувальний баланс | Обмежений внутрішній баланс, що використовується за задокументованими правилами покупок, переказів, комісій та перерозподілу. |
| Ліміт винагород протоколу | Залишкове право на винагороди в активному циклі NFT; он-чейн термін: *Income Limit*. |
| Баланс Token Reserve | Баланс призначеного пулу ліквідності, що підтримує механіки DA. |
| Dev Balance | Протокольні та операційні алокації. |
| Price Impact Balance | Резерв, що використовується задокументованими функціями price-impact. |
