Єдине джерело істини для термінів, що використовуються в документації RWANFTFI.

## Протокол

| Термін | Визначення |
|---|---|
| **Накопичувальний Баланс** | Обмежений внутрішній баланс, на який надходить налаштована частка кваліфікованих партнерських винагород. Невикористані кошти стають придатними до перерозподілу після закінчення строку дії балансу, який наразі становить 180 днів (тимчасово подовжено голосуванням DAO). |
| **Автопродаж** | Запланована обробка залишку DA протягом чотирьох протокольних періодів. |
| **Autobuy** | Автоматичне поновлення придатного NFT, коли його Ліміт винагород протоколу вичерпано. |
| **DA** | Непередаваний утилітарний токен протоколу стандарту BEP-20 з максимальною емісією 21 000 000 одиниць. |
| **Frozen Balance** | Тимчасовий 72-годинний буфер для кваліфікованого Спонсорського бонусу понад залишковий Ліміт винагород протоколу. |
| **GovToken** | Токен управління стандарту ERC20Votes із фіксованою емісією. |
| **Income Limit** | Он-чейн термін для Ліміту винагород протоколу. |
| **NFTM** | Внутрішній лічильник Майнінгу, що використовується в розрахунку Фармінгу. |
| **Фаза 2** | Конфігурація протоколу, активована голосуванням DAO у червні 2026 року: поточний розподіл купівлі NFT і продажі Infinity (L10). |
| **Ліміт винагород протоколу** | Максимальна сукупна сума кваліфікованих винагород, що зараховуються протягом циклу NFT; он-чейн термін: *Income Limit*. |

## Партнерська програма

| Термін | Визначення |
|---|---|
| **Business Sale** | Авторизована DAO передача повної партнерської структури іншому користувачу; з червня 2026 року вимкнена голосуванням DAO. |
| **Подарунковий NFT** | NFT, який не можна купити чи продати; його надають за умовами акцій і програм. Він має власне місце та власний Ліміт винагород протоколу, винагороди за ним розподіляються 50/50 між Звичайним Балансом і Накопичувальним Балансом, і він відкриває доступ до FinFlow. |
| **Matching Bonus** | Умовна винагорода, що охоплює до трьох кваліфікованих рівнів. |
| **Пропущена винагорода** | Активність, яку не зараховано, оскільки не виконано відповідних умов участі. |
| **Партнерська мережа** | Структура, керована смартконтрактом, що визначає розміщення та право на винагороди. |
| **Глибина партнерської мережі** | Максимальна глибина мережі, що враховується в розрахунках кваліфікованого розподілу. |
| **Спонсорський бонус** | Умовна винагорода від кваліфікованої прямої купівлі NFT. |
| **Розподіл по дереву** | Порівневий розрахунок партнерської винагороди в межах допустимої глибини мережі. |

## FinPro

| Термін | Визначення |
|---|---|
| **Claim Spot** | Передзапусковий етап FinPro Marketing, на якому учасник займає місце в структурі та отримує реферальне посилання. |
| **Compound** | Реінвестування нарахувань у базову суму позиції, що збільшує абсолютний розмір майбутніх нарахувань. |
| **Direct Sale** | У FinPro Marketing — 5% від кожного нарахування за позицією особисто запрошеного партнера, незалежно від рівня, на якому цього партнера розміщено. |
| **Earn cap (стеля нарахувань)** | Стеля виплат позиції FinPro; для FinFlow — 200% від початкової базової суми, включно з основною сумою. |
| **FinCore** | Наступний продукт FinPro і перший із FinPro Marketing; його параметри публікуються до запуску. |
| **FinFlow** | Перший продукт FinPro, працює з 8 липня 2026 року: позиції в ринково-нейтральній стратегії. |
| **Ліміт FinFlow** | Максимальна сума відкритих позицій FinFlow для NFT; базовий ліміт дорівнює Ліміту винагород протоколу. |
| **FinFlow NFT** | Непередаваний NFT, що представляє позицію FinFlow. Відкриття позиції не є депозитом. |
| **FinPro** | Лінійка фінансових продуктів екосистеми на rwafinpro.com, які поповнюються безпосередньо з EVM-гаманця користувача. |
| **FinPro Marketing** | Окрема партнерська програма для продуктів FinPro із власною структурою: Direct Sale і 20 рівнів, із зарахуванням 100% на маркетинговий баланс. |
| **Нарахування за позиціями** | Те, що нараховується за позиціями FinPro; нарахування не гарантуються. |
| **Баланс позицій** | Сума всіх відкритих позицій FinPro, зокрема поповнень і реінвестованих сум; відкриває рівні FinPro Marketing. |
| **Refund (повернення коштів)** | Для FinFlow: після того як власник отримав і вивів 50% початкової суми, позицію можна закрити з поверненням залишку до 100% початкової суми. |

## Безпека та сервіси

| Термін | Визначення |
|---|---|
| **AML Checker** | Платна перевірка адреси гаманця на ризики в 19 блокчейнах і 14 стейблкоїнах, доступна в застосунку. |
| **Міст** | Керований сервіс крос-чейн депозитів на bridge.rwanftfi.com для 14 мереж. |
| **Secret Code** | Випадкове слово, яке генерується разом із фінансовим паролем; обов'язкове для будь-якого звернення до служби підтримки з питань безпеки. |
