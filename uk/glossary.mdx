Єдине джерело істини для термінів, що використовуються в документації RWANFTFI.

| Термін | Визначення |
|---|---|
| **Накопичувальний Баланс** | Обмежений внутрішній баланс, на який надходить налаштована частка кваліфікованих партнерських винагород. Невикористані кошти стають придатними до перерозподілу після закінчення строку дії балансу, який наразі становить 180 днів (тимчасово подовжено голосуванням DAO). |
| **Автопродаж** | Запланована обробка залишку DA протягом чотирьох протокольних періодів. |
| **Autobuy** | Автоматичне поновлення придатного NFT, коли його Ліміт винагород протоколу вичерпано. |
| **DA** | Непередаваний утилітарний токен протоколу стандарту BEP-20 з максимальною емісією 21 000 000 одиниць. |
| **Frozen Balance** | Тимчасовий 72-годинний буфер для кваліфікованого Спонсорського бонусу понад залишковий Ліміт винагород протоколу. |
| **GovToken** | Токен управління стандарту ERC20Votes із фіксованою емісією. |
| **Matching Bonus** | Умовна винагорода, що охоплює до трьох кваліфікованих рівнів. |
| **Пропущена винагорода** | Активність, яку не зараховано, оскільки не виконано відповідних умов участі. |
| **NFTM** | Внутрішній лічильник Майнінгу, що використовується в розрахунку Фармінгу. |
| **Партнерська мережа** | Структура, керована смартконтрактом, що визначає розміщення та право на винагороди. |
| **Глибина партнерської мережі** | Максимальна глибина мережі, що враховується в розрахунках кваліфікованого розподілу. |
| **Ліміт винагород протоколу** | Максимальна сукупна сума кваліфікованих винагород, що зараховуються протягом циклу NFT; он-чейн термін: *Income Limit*. |
| **Спонсорський бонус** | Умовна винагорода від кваліфікованої прямої купівлі NFT. |
| **Розподіл по дереву** | Порівневий розрахунок партнерської винагороди в межах допустимої глибини мережі. |
