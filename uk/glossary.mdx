Єдине джерело істини для термінів, що використовуються в документації RWANFTFI.

| Термін | Визначення |
|---|---|
| **Накопичувальний баланс** | Обмежений внутрішній баланс, що отримує налаштовану частку придатних партнерських винагород. |
| **Auto-Sell** | Запланована обробка залишкового DA протягом чотирьох протокольних періодів. |
| **Autobuy** | Автоматичне поновлення придатного NFT, коли його Ліміт винагород протоколу вичерпано. |
| **DA** | Непередаваний службовий токен протоколу стандарту BEP-20 з максимальною емісією 21 000 000 одиниць. |
| **Frozen Balance** | Тимчасовий 72-годинний буфер для придатного Спонсорського бонусу понад залишковий Ліміт винагород протоколу. |
| **GovToken** | Токен управління стандарту ERC20Votes із фіксованою емісією. |
| **Matching Bonus** | Умовна винагорода до трьох придатних рівнів. |
| **Пропущена винагорода** | Активність, не зарахована через невиконання застосовних умов права на участь. |
| **NFTM** | Внутрішній лічильник Майнінгу, що використовується в розрахунку Фармінгу. |
| **Партнерська мережа** | Структура, керована смартконтрактом, що визначає розміщення та право на винагороди. |
| **Глибина партнерської мережі** | Максимальна глибина мережі, включена в розрахунки придатного розподілу. |
| **Ліміт винагород протоколу** | Максимальні сукупні придатні винагороди, що зараховуються протягом циклу NFT; он-чейн термін: *Income Limit*. |
| **Спонсорський бонус** | Умовна винагорода від придатної прямої купівлі NFT. |
| **Розподіл по дереву** | Он-чейн назва Розподілу по партнерській мережі — поуровневий розрахунок винагороди протоколу в межах придатної глибини мережі. |
