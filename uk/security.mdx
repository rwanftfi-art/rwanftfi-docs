## Деталі аудиту

| Пункт | Де перевірити |
|---|---|
| Аудитор | CertiK |
| Дата звіту | 28 квітня 2026 року |
| Перевірений коміт | Точний хеш зазначено в опублікованому звіті. |
| Контракти в обсязі аудиту | Усі перевірені контракти перелічено в опублікованому звіті. |
| Зауваження | ID, рівень серйозності та статус наведено в опублікованому звіті. |
| Усунення | Кожне усунене зауваження пов'язане з відповідною зміною коду у звіті. |
| Відповідність розгортання | Інформація про те, чи відповідають поточні робочі контракти перевіреній версії, публікується окремо. |
| Bug bounty | Актуальний статус, який можна перевірити ззовні, публікується в офіційних каналах. |
