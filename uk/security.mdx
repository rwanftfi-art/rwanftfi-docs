## Деталі аудиту

| Пункт | Де перевірити |
|---|---|
| Аудитор | CertiK |
| Дата звіту | 28 квітня 2026 |
| Аудитований коміт | Точний хеш зазначено в опублікованому звіті. |
| Контракти в скоупі | Усі перевірені контракти перелічено в опублікованому звіті. |
| Знахідки | ID, рівень серйозності та статус перелічено в опублікованому звіті. |
| Усунення | Кожна усунена знахідка пов'язана з відповідною зміною коду у звіті. |
| Відповідність деплою | Чи відповідають поточні production-контракти аудитованій версії, публікується окремо. |
| Bug bounty | Поточний зовнішньо перевірюваний статус публікується в офіційних каналах. |
