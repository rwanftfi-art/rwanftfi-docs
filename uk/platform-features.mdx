## Secret Code

Secret Code — це випадкове слово, яке генерується разом із фінансовим паролем. Цей код обов'язковий для будь-якого звернення до служби підтримки з питань безпеки: без нього підтримка не може опрацювати таке звернення.

<Warning>
  **Тримайте Secret Code у таємниці.** Повідомляйте його лише офіційній службі підтримки й лише тоді, коли звертаєтеся з питанням безпеки. Ніколи не діліться ним у чатах, коментарях чи особистих повідомленнях.
</Warning>

## Месенджер і приватні Web3-чати

Вбудований месенджер показує точний час кожного повідомлення. Його режим **Private Web3 chats** додає наскрізне шифрування на основі протоколу XMTP.

| Характеристика | Як це працює |
|---|---|
| Шифрування | Повідомлення шифруються на пристрої за протоколом MLS (IETF RFC 9420). |
| Зберігання | Повідомлення не зберігаються на серверах платформи. |
| Ідентифікація | EVM-гаманець слугує ідентифікатором; щоб увімкнути режим, достатньо одного підпису без комісії за газ на кожному пристрої. |
| Незалежна перевірка | Аудит бібліотеки libxmtp провела компанія NCC Group. |

<Note>
  Режим захищає вміст повідомлень, але не робить користувачів анонімними. Шифрування діє для нових повідомлень, надісланих у цьому режимі.
</Note>

## Реферальні посилання

У кожного учасника є постійний реферальний код. Реферальні посилання мають єдиний формат:

`share.rwanftfi.com/?ref=CODE`

Старий формат посилань більше не працює: його замінили у вересні 2026 року через проблему з доставкою посилань у Telegram.
