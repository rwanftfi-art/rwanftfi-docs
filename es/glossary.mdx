Una fuente única de verdad para los términos utilizados en la documentación de RWANFTFI.

| Término | Definición |
|---|---|
| **Saldo Acumulativo** | Saldo interno restringido que recibe la cuota configurada de las recompensas de socios elegibles. |
| **Auto-Sell** | Procesamiento programado del DA restante a lo largo de cuatro períodos del protocolo. |
| **Autobuy** | Renovación automática de un NFT elegible cuando se agota su Límite de Recompensas del Protocolo. |
| **DA** | Token de utilidad del protocolo BEP-20 no transferible con un suministro máximo de 21.000.000 unidades. |
| **Frozen Balance** | Ventana temporal de 72 horas para un Bono de Patrocinador calificado que supera el Límite de Recompensas del Protocolo restante. |
| **GovToken** | Token de gobernanza ERC20Votes de suministro fijo. |
| **Matching Bonus** | Recompensa condicional a lo largo de hasta tres niveles calificados. |
| **Ingreso Perdido** | Actividad no acreditada porque no se cumplieron las condiciones de elegibilidad aplicables. |
| **NFTM** | Contador interno de Minería usado en el cálculo del Farming. |
| **Red de Socios** | Estructura gestionada por smart contract utilizada para definir la colocación y la elegibilidad de recompensas. |
| **Profundidad de la Red de Socios** | Profundidad máxima de red incluida en los cálculos de distribución elegibles. |
| **Límite de Recompensas del Protocolo** | Máximo acumulado de recompensas elegibles acreditadas durante un ciclo de NFT; término on-chain: *Income Limit*. |
| **Bono de Patrocinador** | Recompensa condicional por una compra directa calificada de NFT. |
| **Distribución del Árbol** | Nombre on-chain de la Distribución de la Red de Socios — el cálculo de recompensa del protocolo por nivel dentro de la profundidad de red elegible. |
