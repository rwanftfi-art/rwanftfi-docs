## Recomendaciones de Seguridad

<Warning>
  - Nunca comparta una frase semilla, una clave privada, una contraseña financiera, un código TAN ni un código de autenticación de dos factores.
  - Comparta su **Secret Code** únicamente con el soporte oficial y solo en una solicitud relacionada con la seguridad. Sin él, el soporte no puede tramitar una solicitud de seguridad.
  - El soporte nunca le escribe primero y nunca le pide una frase semilla, una clave privada ni un pago por adelantado para "desbloquear" fondos o una cuenta. Cualquier solicitud de este tipo es una estafa.
  - Coteje el dominio con la [lista de dominios oficiales](/es/security#dominios-oficiales) y verifique las direcciones de los contratos.
  - Denuncie las suplantaciones de identidad y el phishing a través del contacto oficial de seguridad.
</Warning>
