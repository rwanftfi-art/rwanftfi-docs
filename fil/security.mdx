## Proteksyon ng Account

Ang audit ay sumasaklaw sa on-chain smart contract layer. Sa application layer, ang mga user account ay karagdagang pinoprotektahan ng ilang independent na mekanismo:

<CardGroup cols={2}>
  <Card title="Three-Level Security" icon="layer-group">
    Tiered protection na naghihiwalay sa login, financial actions, at high-value operations.
  </Card>
  <Card title="TAN Codes" icon="key">
    Single-use Transaction Authentication Numbers na kinakailangan para sa bawat financial transaction.
  </Card>
  <Card title="Financial Password" icon="fingerprint">
    Isang password na hiwalay sa iyong login credentials, kinakailangan lamang para sa paggalaw ng pondo.
  </Card>
  <Card title="2FA + Telegram Bot" icon="telegram">
    Standard two-factor authentication, kasama ang action verification sa pamamagitan ng official Telegram bot.
  </Card>
</CardGroup>

<Info>
  **Ang mga transaksyon ay nangangailangan ng Web3 wallet.** Maaari kang mag-sign in sa dashboard gamit ang email at password upang tingnan ang iyong data, ngunit ang pagsasagawa ng anumang financial action ay nangangailangan ng nakakonektang Web3 wallet (MetaMask, Trust Wallet, o iba pang EVM-compatible wallet).
</Info>

<Warning>
  **Mag-ingat sa mga impostor.** Ang RWANFTFI staff ay hindi kailanman makikipag-ugnay sa iyo muna, hindi kailanman hihingin ang iyong private keys o seed phrase, at hindi kailanman hihingi ng bayad sa labas ng official platform. Palaging i-verify na nasa **rwanftfi.com** ka bago ikonekta ang iyong wallet o ipasok ang mga credentials.
</Warning>
