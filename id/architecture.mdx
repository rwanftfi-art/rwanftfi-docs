## Facet Diamond

| Facet | Fungsi |
|---|---|
| AdminFacet | Peran, parameter, transfer yang disetujui, dan pencetakan NFT khusus. |
| MarketingFacet | Pendaftaran, pembelian NFT, dan perhitungan imbalan mitra. |
| FarmingFacet | Mining NFTM dan Farming DA. |
| PaymentFacet | Deposit, penarikan, voucher, dan transfer saldo. |
| TreeFacet | Penempatan dan kedalaman jaringan mitra. |
| ResolverFacet | Nilai yang kedaluwarsa, pemrosesan voucher, dan penyelesaian Frozen Balance. |
| ViewFacet | Kueri read-only atas pengguna, saldo, dan jaringan. |

## Kontrak NFT

- NFT Reguler menggunakan token ID ganjil.
- NFT Hadiah menggunakan token ID genap.
- NFT Ambassador menggunakan kontrak dan konfigurasi tersendiri.

## Matriks Upgradabilitas

| Komponen | Model |
|---|---|
| Kontrak Diamond | Dapat di-upgrade melalui facet cut. |
| TokenReserve / DA | Dapat di-upgrade melalui mekanisme proxy yang terdokumentasi. |
| Kontrak NFT | Terdokumentasi sebagai tidak dapat di-upgrade. |
| GovToken | Terdokumentasi sebagai tidak dapat di-upgrade, dengan pasokan tetap. |
| AdminContract | Terdokumentasi sebagai tidak dapat di-upgrade. |

## Manajemen Peran

| Peran | Kewenangan Terdokumentasi |
|---|---|
| `ADMIN_ROLE` | Memberikan dan mencabut peran; mengubah parameter protokol yang diizinkan. |
| `SERVICE_ROLE` | Menjalankan operasi layanan otomatis dan lintas-rantai yang terdokumentasi. |
| `SIGNER_ROLE` | Memverifikasi tanda tangan yang diotorisasi untuk tindakan tertentu. |
| `MINTER_ROLE` | Mencetak token atau jenis NFT yang ditetapkan untuk peran tersebut. |

## Skema Saldo

| Saldo | Tujuan |
|---|---|
| Saldo Reguler | Penarikan, pembelian, dan voucher yang memenuhi syarat. |
| Saldo Akumulatif | Saldo internal terbatas yang digunakan berdasarkan aturan terdokumentasi mengenai pembelian, transfer, biaya, dan redistribusi. |
| Batas Imbalan Protokol | Sisa kelayakan imbalan untuk siklus NFT yang aktif; istilah on-chain: *Income Limit*. |
| Token Reserve Balance | Saldo kumpulan likuiditas yang ditetapkan untuk mendukung mekanika DA. |
| Dev Balance | Alokasi protokol dan operasional. |
| Price Impact Balance | Cadangan yang digunakan oleh fungsi price-impact yang terdokumentasi. |
