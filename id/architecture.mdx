## Facet Diamond

| Facet | Fungsi |
|---|---|
| AdminFacet | Penggantian dompet dan pembatasan akun, pencetakan NFT khusus, dan operasi layanan otomatis. |
| ParametersFacet | Parameter protokol, pengaturan NFT, jenis NFT Hadiah, pengaktifan dan penonaktifan fungsi, periode farming, dan rentang biaya. |
| MarketingFacet | Pendaftaran, pembelian NFT, dan perhitungan imbalan mitra. |
| FarmingFacet | Mining NFTM dan Farming DA. |
| PaymentFacet | Deposit, penarikan, voucher, dan transfer saldo. |
| TreeFacet | Penempatan dan kedalaman jaringan mitra. |
| ResolverFacet | Nilai yang kedaluwarsa, pemrosesan voucher, dan penyelesaian Frozen Balance. |
| ViewFacet | Kueri read-only atas pengguna, saldo, dan jaringan. |

Diamond juga mencakup facet standar EIP-2535: DiamondCutFacet untuk upgrade, DiamondLoupeFacet untuk introspeksi, dan OwnershipFacet.

## Kontrak NFT

- NFT Reguler menggunakan token ID ganjil.
- NFT Hadiah menggunakan token ID genap.
- NFT Ambassador menggunakan kontrak dan konfigurasi tersendiri.

## Matriks Upgradabilitas

| Komponen | Model |
|---|---|
| Kontrak Diamond | Dapat di-upgrade melalui facet cut. |
| TokenReserve / DA | Dapat di-upgrade melalui mekanisme proxy yang terdokumentasi. |
| Kontrak NFT | Terdokumentasi sebagai tidak dapat di-upgrade. |
| GovToken | Terdokumentasi sebagai tidak dapat di-upgrade, dengan pasokan tetap. |
| AdminContract | Terdokumentasi sebagai tidak dapat di-upgrade. |

## Manajemen Peran

| Peran | Kewenangan Terdokumentasi |
|---|---|
| Kontrak DAO | Menerapkan pembaruan parameter dalam rentang on-chain, mengubah pengaturan NFT, mengaktifkan atau menonaktifkan fungsi, menetapkan periode farming dan rentang biaya, menyetujui penggantian dompet, serta membatasi atau memulihkan akun. |
| `ADMIN_ROLE` | Memberikan dan mencabut peran; mencetak NFT Hadiah dan NFT Ambassador serta mengelola jenis NFT Hadiah; menetapkan biaya transaksi dalam rentangnya. |
| `SERVICE_ROLE` | Menjalankan operasi layanan otomatis dan lintas-rantai yang terdokumentasi. |
| `SIGNER_ROLE` | Memverifikasi tanda tangan yang diotorisasi untuk tindakan tertentu. |
| `MINTER_ROLE` | Mencetak token atau jenis NFT yang ditetapkan untuk peran tersebut. |
| Pemilik Diamond | Upgrade facet melalui `diamondCut` dan pengalihan kepemilikan. |

Daftar fungsi untuk setiap peran tercantum di bagian sentralisasi [laporan CertiK](/id/security).

## Skema Saldo

| Saldo | Tujuan |
|---|---|
| Saldo Reguler | Penarikan, pembelian, dan voucher yang memenuhi syarat. |
| Saldo Akumulatif | Saldo internal terbatas yang digunakan berdasarkan aturan terdokumentasi mengenai pembelian, transfer, biaya, dan redistribusi. Untuk sementara, masa hidupnya adalah 180 hari selama perbaikan pengaturan ulang timer disiapkan; lihat [Parameter Kontrak](/id/contract-parameters). |
| Batas Imbalan Protokol | Sisa kelayakan imbalan untuk siklus NFT yang aktif; istilah on-chain: *Income Limit*. |
| Token Reserve Balance | Saldo kumpulan likuiditas yang ditetapkan untuk mendukung mekanika DA. |
| Dev Balance | Alokasi protokol dan operasional. |
| Price Impact Balance | Cadangan yang digunakan oleh fungsi price-impact yang terdokumentasi. |

<Note>
  **Saldo FinPro terpisah.** Posisi FinPro dibuka langsung dari dompet EVM pengguna dalam USDT (BEP-20) dan dibayarkan ke dompet yang sama. Posisi tersebut tidak menggunakan Saldo Reguler maupun Saldo Akumulatif. Lihat [FinPro & FinFlow](/id/finpro-finflow).
</Note>
