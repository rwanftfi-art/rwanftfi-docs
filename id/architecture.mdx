RWANFTFI menggunakan arsitektur [EIP-2535](https://eips.ethereum.org/EIPS/eip-2535) Diamond dengan tujuh Facet fungsional, kontrak NFT dan reserve yang terpisah, mekanisme upgradabilitas yang terdefinisi, izin berbasis role, dan beberapa jenis saldo internal.

## Facet Diamond

| Facet | Fungsi |
|---|---|
| AdminFacet | Role, parameter, transfer yang disetujui, dan pencetakan NFT khusus. |
| MarketingFacet | Registrasi, pembelian NFT, dan perhitungan imbalan mitra. |
| FarmingFacet | Mining NFTM dan Farming DA. |
| PaymentFacet | Deposit, penarikan, voucher, dan transfer saldo. |
| TreeFacet | Penempatan dan kedalaman jaringan mitra. |
| ResolverFacet | Nilai kedaluwarsa, pemrosesan voucher, dan penyelesaian Frozen Balance. |
| ViewFacet | Kueri read-only untuk data pengguna, saldo, dan jaringan. |

## Kontrak NFT

- NFT Reguler menggunakan token ID ganjil.
- NFT Hadiah menggunakan token ID genap.
- NFT Ambassador menggunakan kontrak dan konfigurasi terpisah.

## Matriks Upgradabilitas

| Komponen | Model |
|---|---|
| Kontrak Diamond | Dapat di-upgrade melalui facet cuts. |
| TokenReserve / DA | Dapat di-upgrade melalui mekanisme proxy yang terdokumentasi. |
| Kontrak NFT | Terdokumentasi sebagai tidak dapat di-upgrade. |
| GovToken | Terdokumentasi sebagai tidak dapat di-upgrade dengan pasokan tetap. |
| AdminContract | Terdokumentasi sebagai tidak dapat di-upgrade. |

## Manajemen Role

| Role | Wewenang yang Terdokumentasi |
|---|---|
| `ADMIN_ROLE` | Memberikan dan mencabut role; mengubah parameter protokol yang diizinkan. |
| `SERVICE_ROLE` | Menjalankan operasi layanan otomatis dan lintas-rantai yang terdokumentasi. |
| `SIGNER_ROLE` | Memverifikasi tanda tangan resmi untuk tindakan tertentu. |
| `MINTER_ROLE` | Mencetak token atau tipe NFT yang ditetapkan untuk role tersebut. |

## Skema Saldo

| Saldo | Tujuan |
|---|---|
| Saldo Reguler | Penarikan, pembelian, dan voucher yang memenuhi syarat. |
| Saldo Akumulatif | Saldo internal terbatas yang digunakan berdasarkan aturan pembelian, transfer, biaya, dan redistribusi yang terdokumentasi. |
| Batas Reward Protokol | Sisa kelayakan reward untuk siklus NFT yang aktif; istilah on-chain: *Income Limit*. |
| Saldo Cadangan Token | Saldo pool likuiditas yang ditunjuk untuk mendukung mekanika DA. |
| Saldo Dev | Alokasi protokol dan operasional. |
| Saldo Dampak Harga | Cadangan yang digunakan oleh fungsi dampak-harga yang terdokumentasi. |
