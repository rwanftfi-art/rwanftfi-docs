RWANFTFI 文档所用术语的统一可信来源。

## 协议

| 术语 | 定义 |
|---|---|
| **累积余额** | 受限的内部余额，接收符合条件的合作伙伴奖励中按配置划入的份额。未使用的资金在余额生命周期届满后可被再分配，目前该生命周期为 180 天（经 DAO 投票临时延长）。 |
| **自动出售** | 在四个协议时段内对剩余 DA 进行的计划处理。 |
| **Autobuy** | 当符合条件的 NFT 的协议奖励上限耗尽时，对其进行的自动续约。 |
| **DA** | 不可转让的 BEP-20 协议实用代币，最大供应量为 21,000,000 单位。 |
| **冻结余额** | 针对超出剩余协议奖励上限的合格推荐人奖金所设的 72 小时临时缓冲。 |
| **GovToken** | 固定供应量的 ERC20Votes 治理代币。 |
| **Income Limit** | 协议奖励上限的链上术语。 |
| **NFTM** | 用于农场计算的内部挖矿计数器。 |
| **第二阶段** | 2026 年 6 月经 DAO 投票启动的协议配置：当前的 NFT 购买分配与 Infinity（L10）销售。 |
| **协议奖励上限** | 一个 NFT 周期内可记入的符合条件的奖励的最大累计金额；链上术语：*Income Limit*。 |

## 合作伙伴计划

| 术语 | 定义 |
|---|---|
| **Business Sale** | 经 DAO 授权、将完整合作伙伴结构转让给其他用户的功能；自 2026 年 6 月起已通过 DAO 投票禁用。 |
| **礼品 NFT** | 不可购买也不可出售的 NFT，根据促销活动与各类计划授予。它拥有自己的位置与协议奖励上限，其奖励在常规余额与累积余额之间按 50/50 分配，并可解锁 FinFlow。 |
| **对等奖金（Matching Bonus）** | 最多覆盖三个合格层级的附条件奖励。 |
| **错失奖励** | 因未满足适用资格条件而未被记入的活动。 |
| **合作伙伴网络** | 由智能合约管理、用于确定位置安排与奖励资格的结构。 |
| **合作伙伴网络深度** | 纳入符合条件的分配计算的最大网络深度。 |
| **推荐人奖金（Sponsor Bonus）** | 来自合格直接 NFT 购买的附条件奖励。 |
| **二叉树分配** | 在符合条件的网络深度内按层级计算的合作伙伴奖励。 |

## FinPro

| 术语 | 定义 |
|---|---|
| **Claim Spot** | FinPro Marketing 的预启动阶段，参与者在此阶段于结构中占据位置并获得推荐链接。 |
| **Compound** | 将应计额再投资至仓位的基数中，从而提高未来应计额的绝对金额。 |
| **Direct Sale** | 在 FinPro Marketing 中，亲自邀请的合作伙伴每笔仓位应计额的 5%，无论该合作伙伴被安排在哪个层级。 |
| **Earn cap（应计上限）** | FinPro 仓位的发放上限；对于 FinFlow，为初始基数的 200%，本金包含在内。 |
| **FinCore** | 下一个 FinPro 产品，也是首个启用 FinPro Marketing 的产品；其参数将在上线前公布。 |
| **FinFlow** | 首个 FinPro 产品，自 2026 年 7 月 8 日起已上线：市场中性策略中的仓位。 |
| **FinFlow 额度** | 一个 NFT 可持有的未关闭 FinFlow 仓位的最高总额；其基础额度等于协议奖励上限。 |
| **FinFlow NFT** | 代表 FinFlow 仓位的不可转让 NFT。开立仓位并非存款。 |
| **FinPro** | 生态系统的金融产品线，位于 rwafinpro.com，资金直接来自用户的 EVM 钱包。 |
| **FinPro Marketing** | 面向 FinPro 产品的独立合作伙伴计划，拥有自己的结构：Direct Sale 加 20 个层级，100% 记入营销余额。 |
| **仓位应计额** | FinPro 仓位产生的应计额；应计额不作保证。 |
| **仓位余额** | 所有未关闭 FinPro 仓位的总额，包括追加资金与再投资金额；仓位余额决定开放的 FinPro Marketing 层级。 |
| **Refund（退款）** | 对于 FinFlow：当持有者已获得并提取初始金额的 50% 后，可关闭仓位，并退还补足至初始金额 100% 的剩余部分。 |

## 安全与服务

| 术语 | 定义 |
|---|---|
| **AML Checker** | 应用内的付费钱包地址风险检测，覆盖 19 条区块链与 14 种稳定币。 |
| **跨链桥** | 位于 bridge.rwanftfi.com 的托管式跨链充值服务，支持 14 个网络。 |
| **Secret Code** | 与财务密码一同生成的随机单词；任何安全相关的支持请求均须提供。 |
