RWANFTFI 文档中所使用术语的统一权威参考。

| 术语 | 定义 |
|---|---|
| **累积余额** | 接收符合条件的合作伙伴奖励中约定份额的受限内部余额。 |
| **Auto-Sell** | 在四个协议周期内对剩余 DA 进行的计划处理。 |
| **Autobuy** | 当符合条件的 NFT 的协议奖励上限耗尽时,对其进行的自动续约。 |
| **DA** | 一种不可转让的 BEP-20 协议实用代币,最大供应量为 21,000,000 枚。 |
| **Frozen Balance** | 一种为期 72 小时的临时缓冲机制,适用于超过剩余协议奖励上限的符合条件的推荐人奖金。 |
| **GovToken** | 固定供应量的 ERC20Votes 治理代币。 |
| **Matching Bonus** | 一项跨最多三个符合条件层级的条件性奖励。 |
| **丢失收入** | 因未满足适用资格条件而未被记入的活动收益。 |
| **NFTM** | 用于农场计算的内部挖矿计数器。 |
| **合作伙伴网络** | 由智能合约管理、用于定义位置安排与奖励资格的结构。 |
| **合作伙伴网络深度** | 纳入符合条件的分配计算中的最大网络深度。 |
| **协议奖励上限** | 在一个 NFT 周期内可记入的最大累计符合条件奖励;链上术语为 *Income Limit*。 |
| **推荐人奖金** | 来自符合条件的直接 NFT 购买的条件性奖励。 |
| **二叉树分配** | 在符合条件的网络深度范围内,按层级计算的合作伙伴奖励。 |
