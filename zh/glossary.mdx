<AccordionGroup>
  <Accordion title="累积余额（Accumulative Balance）">
    强制系统钱包，存储用户营销奖励的 20%，仅可用于 NFT 回购或升级。120 天衰减：70% 留存，30% 转给上级推荐人。
  </Accordion>
  <Accordion title="自动出售（Auto-sell）">
    TokenStack 到期时自动出售 DA。用户获得 70% USDT（比手动少 5%）。30% 代币永久销毁。
  </Accordion>
  <Accordion title="Autobuy（3/3）">
    智能合约功能，当收入上限归零时自动回购 NFT，最多 3 次，防止错过营销奖励。升级后重置为 3/3。不适用于 Elite（L9–L10）。
  </Accordion>
  <Accordion title="业务出售（Business Sale）">
    通过 DAO 投票将整个业务结构（合作树）转让给另一用户。佣金：500 USDT（由 DAO 调节）。
  </Accordion>
  <Accordion title="CeFi（中心化金融）">
    与 DeFi 组件并行集成到生态系统中的传统金融服务和产品。
  </Accordion>
  <Accordion title="压缩（Compression）">
    智能合约算法，跳过收入上限为零或 NFT 等级不足的用户，将奖励向上传递给下一位合格用户。实现「无限深度」收益。
  </Accordion>
  <Accordion title="DA（通缩资产）">
    生态系统核心经济代币。硬顶 2100 万枚，100% USDT 流动性池支撑。价格 = 流动性 ÷ 供应量。每次出售都销毁代币——价格在数学上只增不减。
  </Accordion>
  <Accordion title="跨链桥">
    内置桥接工具，允许用户从任何受支持的区块链网络为账户充值。存款通过 SERVICE_ROLE 在链上处理。
  </Accordion>
  <Accordion title="DeFi（去中心化金融）">
    基于区块链技术、无中介的金融服务。RWANFTFI 生态系统的三大支柱之一（RWA + DeFi + CeFi）。
  </Accordion>
  <Accordion title="FinPro（金融产品）">
    通过平台提供的金融产品和服务套件。2026 年 Q3 推出。
  </Accordion>
  <Accordion title="Gift NFT">
    不可出售的推广 NFT，将用户永久放置在二叉树中。无法购买——通过推广或职业等级获得。
  </Accordion>
  <Accordion title="收入上限（Income Limit）">
    特定 NFT 在需要续期前可产生的最大 USDT 奖励。上限归零时，所有奖励被跳过（压缩激活）。
  </Accordion>
  <Accordion title="Lost Income（错过收入）">
    通知用户由于 NFT 等级不足或收入上限耗尽而错过营销奖励。资金传递给上方下一位合格参与者。
  </Accordion>
  <Accordion title="Matching Bonus">
    次级奖励系统——从直属合作伙伴的收入中获取 5% + 5% + 5%，跨三个层级。需 L4 NFT + 个人销售里程碑（1,000 和 3,000 USDT）解锁。
  </Accordion>
  <Accordion title="NFTM">
    内部挖矿计数器（非代币），在 40–45 天挖矿阶段生成。须在 72 小时内质押以开始农耕 DA。无市场价值。
  </Accordion>
  <Accordion title="回购（Rebuy）">
    回购同级 NFT 以刷新收入上限。当剩余上限低于初始值的 30% 时可用。
  </Accordion>
  <Accordion title="RWA（实体资产）">
    在区块链上代币化的实物资产（房地产、基础设施、企业）。长期战略方向——2027–2028 年推出。
  </Accordion>
  <Accordion title="Spillover">
    上级推荐人的邀请自动放置到参与者的二叉树中。产生被动营业额和完整营销奖励——与直接邀请相同。
  </Accordion>
  <Accordion title="VERA AI">
    计划于 2027–2028 年推出的 AI 个人金融助手，帮助用户使用生态系统的金融工具。
  </Accordion>
  <Accordion title="代金券（Voucher）">
    用户生成的数字优惠券——最低 5 USDT，365 天有效期。可覆盖 NFT 购买价格的 100%。0% 佣金转让。不可与累积余额合并使用。
  </Accordion>
</AccordionGroup>
