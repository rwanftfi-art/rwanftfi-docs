## Diamond Facet

| Facet | 功能 |
|---|---|
| AdminFacet | 角色、参数、经批准的转让以及特殊 NFT 铸造。 |
| MarketingFacet | 注册、NFT 购买与合作伙伴奖励计算。 |
| FarmingFacet | NFTM 挖矿与 DA 农场。 |
| PaymentFacet | 充值、提现、代金券与余额转账。 |
| TreeFacet | 合作伙伴网络的位置安排与深度。 |
| ResolverFacet | 过期金额、代金券处理与冻结余额结算。 |
| ViewFacet | 用户、余额与网络的只读查询。 |

## NFT 合约

- 常规 NFT 使用奇数 token ID。
- 礼品 NFT 使用偶数 token ID。
- 大使 NFT 使用独立的合约与配置。

## 可升级性矩阵

| 组件 | 模式 |
|---|---|
| Diamond 合约 | 可通过 Facet 切割升级。 |
| TokenReserve / DA | 可通过文档所述的代理机制升级。 |
| NFT 合约 | 文档记载为不可升级。 |
| GovToken | 文档记载为不可升级，供应量固定。 |
| AdminContract | 文档记载为不可升级。 |

## 角色管理

| 角色 | 文档所述权限 |
|---|---|
| `ADMIN_ROLE` | 授予和撤销角色；修改允许变更的协议参数。 |
| `SERVICE_ROLE` | 执行文档所述的自动化与跨链服务操作。 |
| `SIGNER_ROLE` | 验证指定操作的授权签名。 |
| `MINTER_ROLE` | 铸造分配给该角色的代币或 NFT 类型。 |

## 余额结构

| 余额 | 用途 |
|---|---|
| 常规余额 | 符合条件的提现、购买与代金券。 |
| 累积余额 | 受限的内部余额，按文档所述的购买、转账、手续费与再分配规则使用。 |
| 协议奖励上限 | 当前有效 NFT 周期内剩余的奖励资格；链上术语：*Income Limit*。 |
| Token Reserve 余额 | 支持 DA 机制的指定流动性池余额。 |
| 开发余额 | 协议与运营分配。 |
| 价格影响余额 | 由文档所述的价格影响函数使用的储备。 |

## 支付优先级

<Steps>
  <Step title="已选择的有效代金券">
    如果用户在结账时明确使用有效代金券，则优先消耗其面额。
  </Step>
  <Step title="累积余额">
    在符合条件且被选择时使用，适用文档所述的手续费规则。
  </Step>
  <Step title="常规余额">
    剩余金额从常规余额中扣除。
  </Step>
</Steps>

<Note>
  [BNB Smart Chain](https://www.bnbchain.org/en/bnb-smart-chain) 上的所有交易都需要以 **BNB** 支付标准网络 gas 费，与生态系统内使用的 [USDT](https://tether.to/) 余额相互独立。合约部署与余额均可在 [BscScan](https://bscscan.com/) 上公开核验。
</Note>
