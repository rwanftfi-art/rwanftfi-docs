RWANFTFI 采用 [EIP-2535](https://eips.ethereum.org/EIPS/eip-2535) Diamond 架构,包含七个功能性 Facet、独立的 NFT 与储备合约、明确的可升级机制、基于角色的权限体系,以及多种内部余额类型。

## Diamond Facet

| Facet | 功能 |
|---|---|
| AdminFacet | 角色管理、参数设置、批准的转账,以及特殊 NFT 铸造。 |
| MarketingFacet | 用户注册、NFT 购买与合作伙伴奖励计算。 |
| FarmingFacet | NFTM 挖矿与 DA 农场。 |
| PaymentFacet | 充值、提现、代金券与余额转账。 |
| TreeFacet | 合作伙伴网络位置安排与深度管理。 |
| ResolverFacet | 过期数值处理、代金券处理与 Frozen Balance 解析。 |
| ViewFacet | 用户、余额与网络数据的只读查询。 |

## NFT 合约

- 常规 NFT 使用奇数 token ID。
- 礼品 NFT 使用偶数 token ID。
- 大使 NFT 使用独立的合约与配置。

## 可升级性矩阵

| 组件 | 升级模式 |
|---|---|
| Diamond 合约 | 可通过 Facet 切割升级。 |
| TokenReserve / DA | 可通过文档规定的代理机制升级。 |
| NFT 合约 | 文档规定为不可升级。 |
| GovToken | 文档规定为不可升级,且供应量固定。 |
| AdminContract | 文档规定为不可升级。 |

## 角色管理

| 角色 | 文档规定的权限 |
|---|---|
| `ADMIN_ROLE` | 授予与撤销角色;变更允许调整的协议参数。 |
| `SERVICE_ROLE` | 执行文档规定的自动化与跨链服务操作。 |
| `SIGNER_ROLE` | 验证特定操作所需的授权签名。 |
| `MINTER_ROLE` | 铸造该角色被授权的代币或 NFT 类型。 |

## 余额结构

| 余额类型 | 用途 |
|---|---|
| 常规余额 | 符合条件的提现、购买与代金券使用。 |
| 累积余额 | 受限的内部余额,依据文档规定的购买、转账、手续费与再分配规则使用。 |
| 协议奖励上限 | 当前 NFT 周期的剩余奖励资格;链上术语为 *Income Limit*。 |
| 代币储备余额 | 支持 DA 机制的指定流动性池余额。 |
| 开发余额 | 协议与运营分配资金。 |
| 价格影响余额 | 文档规定的价格影响功能所使用的储备金。 |

## 支付优先级

<Steps>
  <Step title="已选择的有效代金券">
    若用户在结账时明确使用有效代金券,其面值将被优先扣减。
  </Step>
  <Step title="累积余额">
    在符合条件并被选用时,依据文档规定的手续费规则扣减。
  </Step>
  <Step title="常规余额">
    剩余金额从常规余额中扣除。
  </Step>
</Steps>

<Note>
  [币安智能链](https://www.bnbchain.org/en/bnb-smart-chain)上的所有交易均需以 **BNB** 支付标准网络 gas 费,这与生态系统内使用的 [USDT](https://tether.to/) 余额相互独立。合约部署与余额可在 [BscScan](https://bscscan.com/) 上公开核验。
</Note>
