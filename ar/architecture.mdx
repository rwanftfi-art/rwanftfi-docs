يعتمد RWANFTFI بنية [EIP-2535](https://eips.ethereum.org/EIPS/eip-2535) من نوع Diamond بسبع وحدات وظيفية (Facets)، وعقود منفصلة لـ NFT والاحتياطي، وآليات ترقية مُحدَّدة، وصلاحيات قائمة على الأدوار، وأنواع متعدّدة من الأرصدة الداخلية.

## وحدات Diamond (Facets)

| الوحدة (Facet) | الوظيفة |
|---|---|
| AdminFacet | الأدوار، المعايير، التحويلات المعتمَدة، وسكّ NFT الخاصة. |
| MarketingFacet | التسجيل، مشتريات NFT، وحساب مكافآت الشركاء. |
| FarmingFacet | تعدين NFTM وزراعة DA. |
| PaymentFacet | الإيداعات، السحوبات، القسائم، وتحويلات الأرصدة. |
| TreeFacet | تموضع شبكة الشركاء وعمقها. |
| ResolverFacet | القيم المنتهية، معالجة القسائم، وتسوية Frozen Balance. |
| ViewFacet | استعلامات للقراءة فقط لبيانات المستخدمين والأرصدة والشبكة. |

## عقود NFT

- تستخدم NFT العادية معرّفات رموز فردية.
- تستخدم NFT الهدية معرّفات رموز زوجية.
- تستخدم NFT السفير عقداً وتهيئة منفصلَين.

## مصفوفة قابلية الترقية

| المكوّن | النموذج |
|---|---|
| عقد Diamond | قابل للترقية عبر Facet cuts. |
| TokenReserve / DA | قابل للترقية عبر آلية الوكيل الموثَّقة. |
| عقود NFT | موثَّقة كغير قابلة للترقية. |
| GovToken | موثَّق كغير قابل للترقية وبعرض ثابت. |
| AdminContract | موثَّق كغير قابل للترقية. |

## إدارة الأدوار

| الدور | الصلاحية الموثَّقة |
|---|---|
| `ADMIN_ROLE` | منح الأدوار وإلغاؤها؛ تغيير معايير البروتوكول المسموح بتعديلها. |
| `SERVICE_ROLE` | تنفيذ العمليات الآلية والخدمية عبر السلاسل الموثَّقة. |
| `SIGNER_ROLE` | التحقّق من التواقيع المعتمَدة لإجراءات محدَّدة. |
| `MINTER_ROLE` | سكّ الرمز أو نوع NFT المُسنَد إلى ذلك الدور. |

## مخطّط الأرصدة

| الرصيد | الغرض |
|---|---|
| الرصيد العادي | السحوبات والمشتريات والقسائم المؤهَّلة. |
| الرصيد التراكمي | رصيد داخلي مقيَّد يُستخدَم وفق قواعد الشراء والتحويل والرسوم وإعادة التوزيع الموثَّقة. |
| حدّ مكافآت البروتوكول | أهلية المكافآت المتبقّية لدورة NFT النشطة؛ المصطلح على السلسلة: *Income Limit*. |
| رصيد احتياطي الرمز | رصيد مجمع السيولة المخصَّص الداعم لآليات DA. |
| رصيد التطوير | مخصَّصات البروتوكول والتشغيل. |
| رصيد تأثير السعر | احتياطي تستخدمه دوال تأثير السعر الموثَّقة. |
