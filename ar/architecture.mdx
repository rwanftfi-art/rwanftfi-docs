## وحدات Diamond (Facets)

| الوحدة | الوظيفة |
|---|---|
| AdminFacet | الأدوار، والمعايير، والتحويلات المعتمَدة، وسكّ رموز NFT الخاصة. |
| MarketingFacet | التسجيل، ومشتريات NFT، وحسابات مكافآت الشركاء. |
| FarmingFacet | تعدين NFTM وزراعة DA. |
| PaymentFacet | الإيداعات، والسحوبات، والقسائم، وتحويلات الأرصدة. |
| TreeFacet | التموضع في شبكة الشركاء وعمقها. |
| ResolverFacet | القيم المنتهية، ومعالجة القسائم، وتسوية الرصيد المجمَّد. |
| ViewFacet | استعلامات للقراءة فقط عن المستخدمين والأرصدة والشبكة. |

## عقود NFT

- تستخدم رموز NFT العادية معرّفات رموز فردية.
- تستخدم رموز NFT الهدية معرّفات رموز زوجية.
- تستخدم رموز Ambassador NFT عقداً وإعداداً منفصلَين.

## مصفوفة قابلية الترقية

| المكوّن | النموذج |
|---|---|
| عقد Diamond | قابل للترقية عبر Facet cuts. |
| TokenReserve / DA | قابل للترقية عبر آلية الوكيل (proxy) الموثَّقة. |
| عقود NFT | موثَّقة بوصفها غير قابلة للترقية. |
| GovToken | موثَّق بوصفه غير قابل للترقية وذا عرض ثابت. |
| AdminContract | موثَّق بوصفه غير قابل للترقية. |

## إدارة الأدوار

| الدور | الصلاحيات الموثَّقة |
|---|---|
| `ADMIN_ROLE` | منح الأدوار وسحبها؛ وتغيير معايير البروتوكول المسموح بتغييرها. |
| `SERVICE_ROLE` | تنفيذ عمليات الخدمة الآلية والعابرة للسلاسل الموثَّقة. |
| `SIGNER_ROLE` | التحقق من التواقيع المعتمَدة لإجراءات محدَّدة. |
| `MINTER_ROLE` | سكّ الرمز أو نوع NFT المسنَد إلى ذلك الدور. |

## مخطط الأرصدة

| الرصيد | الغرض |
|---|---|
| الرصيد العادي | السحوبات والمشتريات والقسائم المؤهَّلة. |
| الرصيد التراكمي | رصيد داخلي مقيَّد يُستخدَم وفق القواعد الموثَّقة للشراء والتحويل والرسوم وإعادة التوزيع. |
| سقف مكافآت البروتوكول | الأهلية المتبقية للمكافآت في دورة NFT النشطة؛ المصطلح على السلسلة: *Income Limit*. |
| رصيد Token Reserve | رصيد مجمع السيولة المخصَّص الذي يدعم آليات DA. |
| رصيد التطوير | مخصصات البروتوكول والتشغيل. |
| رصيد تأثير السعر | احتياطي تستخدمه وظائف تأثير السعر (price impact) الموثَّقة. |
