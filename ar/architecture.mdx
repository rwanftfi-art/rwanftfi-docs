## وحدات Diamond (Facets)

| الوحدة | الوظيفة |
|---|---|
| AdminFacet | تغيير المحافظ وتقييد الحسابات، وسكّ رموز NFT الخاصة، وعمليات الخدمة الآلية. |
| ParametersFacet | معايير البروتوكول، وإعدادات NFT، وأنواع رموز NFT الهدية، وتفعيل الوظائف وتعطيلها، وفترات الزراعة، ونطاقات الرسوم. |
| MarketingFacet | التسجيل، ومشتريات NFT، وحسابات مكافآت الشركاء. |
| FarmingFacet | تعدين NFTM وزراعة DA. |
| PaymentFacet | الإيداعات، والسحوبات، والقسائم، وتحويلات الأرصدة. |
| TreeFacet | التموضع في شبكة الشركاء وعمقها. |
| ResolverFacet | القيم المنتهية، ومعالجة القسائم، وتسوية الرصيد المجمَّد. |
| ViewFacet | استعلامات للقراءة فقط عن المستخدمين والأرصدة والشبكة. |

يتضمن Diamond أيضاً الوحدات القياسية وفق EIP-2535، وهي: DiamondCutFacet للترقيات، وDiamondLoupeFacet للاستعلام عن بنية العقد (introspection)، وOwnershipFacet.

## عقود NFT

- تستخدم رموز NFT العادية معرّفات رموز فردية.
- تستخدم رموز NFT الهدية معرّفات رموز زوجية.
- تستخدم رموز Ambassador NFT عقداً وإعداداً منفصلَين.

## مصفوفة قابلية الترقية

| المكوّن | النموذج |
|---|---|
| عقد Diamond | قابل للترقية عبر Facet cuts. |
| TokenReserve / DA | قابل للترقية عبر آلية الوكيل (proxy) الموثَّقة. |
| عقود NFT | موثَّقة بوصفها غير قابلة للترقية. |
| GovToken | موثَّق بوصفه غير قابل للترقية وذا عرض ثابت. |
| AdminContract | موثَّق بوصفه غير قابل للترقية. |

## إدارة الأدوار

| الدور | الصلاحيات الموثَّقة |
|---|---|
| عقد DAO | يطبّق تحديثات المعايير ضمن النطاقات المحدَّدة على السلسلة، ويغيّر إعدادات NFT، ويفعّل الوظائف أو يعطّلها، ويحدّد فترات الزراعة ونطاقات الرسوم، ويوافق على تغيير المحافظ، ويقيّد الحسابات أو يستعيدها. |
| `ADMIN_ROLE` | منح الأدوار وسحبها؛ وسكّ رموز NFT الهدية ورموز Ambassador NFT، وإدارة أنواع رموز NFT الهدية؛ وتحديد رسم المعاملة ضمن نطاقه. |
| `SERVICE_ROLE` | تنفيذ عمليات الخدمة الآلية والعابرة للسلاسل الموثَّقة. |
| `SIGNER_ROLE` | التحقق من التواقيع المعتمَدة لإجراءات محدَّدة. |
| `MINTER_ROLE` | سكّ الرمز أو نوع NFT المسنَد إلى ذلك الدور. |
| مالك Diamond | ترقية الوحدات (Facets) عبر `diamondCut`، ونقل الملكية. |

ترد القائمة التفصيلية لوظائف كل دور في قسم المركزية من [تقرير CertiK](/ar/security).

## مخطط الأرصدة

| الرصيد | الغرض |
|---|---|
| الرصيد العادي | السحوبات والمشتريات والقسائم المؤهَّلة. |
| الرصيد التراكمي | رصيد داخلي مقيَّد يُستخدَم وفق القواعد الموثَّقة للشراء والتحويل والرسوم وإعادة التوزيع. ويبلغ عمره مؤقتاً 180 يوماً ريثما يُعَدّ إصلاح لإعادة ضبط المؤقت؛ انظر [معايير العقد](/ar/contract-parameters). |
| سقف مكافآت البروتوكول | الأهلية المتبقية للمكافآت في دورة NFT النشطة؛ المصطلح على السلسلة: *Income Limit*. |
| رصيد Token Reserve | رصيد مجمع السيولة المخصَّص الذي يدعم آليات DA. |
| رصيد التطوير | مخصصات البروتوكول والتشغيل. |
| رصيد تأثير السعر | احتياطي تستخدمه وظائف تأثير السعر (price impact) الموثَّقة. |

<Note>
  **أرصدة FinPro منفصلة.** تُفتَح مراكز FinPro مباشرةً من محفظة EVM الخاصة بالمستخدم بعملة USDT (BEP-20)، وتُدفَع المبالغ إلى المحفظة نفسها. ولا يُستخدَم فيها الرصيد العادي ولا الرصيد التراكمي. انظر [FinPro وFinFlow](/ar/finpro-finflow).
</Note>
