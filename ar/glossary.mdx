مرجع موحَّد للمصطلحات المُستخدَمة عبر وثائق RWANFTFI.

| المصطلح | التعريف |
|---|---|
| **الرصيد التراكمي** | رصيد داخلي مقيَّد يستلم الحصّة المُهيَّأة من مكافآت الشركاء المؤهَّلة. |
| **Auto-Sell** | معالجة مجدوَلة لـ DA المتبقّية عبر أربع فترات بروتوكول. |
| **Autobuy** | تجديد تلقائي لـ NFT مؤهَّل عند استنفاد حدّ مكافآت البروتوكول الخاص به. |
| **DA** | رمز بروتوكول منفعي غير قابل للتحويل من معيار BEP-20 بحدّ أقصى للعرض يبلغ 21,000,000 وحدة. |
| **Frozen Balance** | نافذة احتجاز مؤقّتة مدّتها 72 ساعة لمكافأة راعٍ مؤهَّلة تتجاوز حدّ مكافآت البروتوكول المتبقّي. |
| **GovToken** | رمز حوكمة بعرض ثابت من معيار ERC20Votes. |
| **Matching Bonus** | مكافأة مشروطة عبر ما يصل إلى ثلاثة مستويات مؤهَّلة. |
| **المكافأة الفائتة** | نشاط لم يُودَع بسبب عدم استيفاء شروط الأهلية المُطبَّقة. |
| **NFTM** | عدّاد تعدين داخلي يُستخدَم في حساب الزراعة. |
| **شبكة الشركاء** | هيكل تُديره العقود الذكية يُستخدَم لتحديد التموضع وأهلية المكافآت. |
| **عمق شبكة الشركاء** | أقصى عمق شبكة مُدرَج في حسابات التوزيع المؤهَّلة. |
| **حدّ مكافآت البروتوكول** | الحدّ الأقصى التراكمي للمكافآت المؤهَّلة المُودَعة خلال دورة NFT؛ المصطلح على السلسلة: *Income Limit*. |
| **مكافأة الراعي** | مكافأة مشروطة من عملية شراء NFT مباشرة مؤهَّلة. |
| **توزيع الشجرة** | الاسم على السلسلة لتوزيع شبكة الشركاء — حساب مكافأة البروتوكول لكلّ مستوى ضمن عمق الشبكة المؤهَّل. |
