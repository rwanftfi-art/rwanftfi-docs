مرجع موحَّد للمصطلحات المستخدَمة في وثائق RWANFTFI.

| المصطلح | التعريف |
|---|---|
| **الرصيد التراكمي** | رصيد داخلي مقيَّد يتلقى الحصة المحدَّدة في الإعدادات من مكافآت الشركاء المؤهَّلة. وتصبح الأموال غير المستخدَمة مؤهَّلة لإعادة التوزيع بعد انقضاء عمر الرصيد، البالغ حالياً 180 يوماً (مُدِّد مؤقتاً بتصويت DAO). |
| **البيع التلقائي** | المعالجة المجدوَلة لـ DA المتبقي على أربع فترات يحدّدها البروتوكول. |
| **Autobuy** | التجديد التلقائي لـ NFT مؤهَّل عند استنفاد سقف مكافآت البروتوكول الخاص به. |
| **DA** | رمز منفعة للبروتوكول غير قابل للتحويل وفق معيار BEP-20، بحد أقصى للعرض يبلغ 21,000,000 وحدة. |
| **الرصيد المجمَّد** | احتجاز مؤقت لمدة 72 ساعة لمكافأة راعٍ مستوفية للشروط تتجاوز سقف مكافآت البروتوكول المتبقي. |
| **GovToken** | رمز حوكمة وفق معيار ERC20Votes بعرض ثابت. |
| **مكافأة المطابقة** | مكافأة مشروطة عبر ما يصل إلى ثلاثة مستويات مستوفية للشروط. |
| **المكافأة المفقودة** | نشاط لم تُضَف مكافأته لعدم استيفاء شروط الأهلية المطبَّقة. |
| **NFTM** | عدّاد تعدين داخلي يُستخدَم في حساب الزراعة. |
| **شبكة الشركاء** | هيكل يديره العقد الذكي ويُستخدَم لتحديد التموضع والأهلية للمكافآت. |
| **عمق شبكة الشركاء** | أقصى عمق للشبكة يُدرَج في حسابات التوزيع المؤهَّلة. |
| **سقف مكافآت البروتوكول** | الحد الأقصى للمكافآت المؤهَّلة التراكمية التي تُضاف خلال دورة NFT؛ المصطلح على السلسلة: *Income Limit*. |
| **مكافأة الراعي** | مكافأة مشروطة ناتجة عن شراء NFT مباشر مستوفٍ للشروط. |
| **توزيع الشجرة** | حساب مكافآت الشركاء لكل مستوى ضمن عمق الشبكة المؤهَّل. |
