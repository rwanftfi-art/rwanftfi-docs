## Secret Code

يُعدّ Secret Code كلمة عشوائية تُولَّد مع كلمة المرور المالية. وهو مطلوب لأي طلب يُقدَّم إلى الدعم ويتعلق بالأمان: فمن دونه لا يستطيع فريق الدعم اتخاذ أي إجراء بشأن هذا الطلب.

<Warning>
  **يُرجى الحفاظ على سرية Secret Code.** فلا يُشارَك إلا مع فريق الدعم الرسمي، وعند تقديم طلب يتعلق بالأمان فقط. ولا يُشارَك أبداً في المحادثات أو التعليقات أو الرسائل الخاصة.
</Warning>

## خدمة المراسلة ومحادثات Web3 الخاصة

تعرض خدمة المراسلة المدمجة الوقت الدقيق لكل رسالة. ويضيف وضع **Private Web3 chats** فيها التشفير التام بين الطرفين عبر بروتوكول XMTP.

| الخاصية | آلية العمل |
|---|---|
| التشفير | تُشفَّر الرسائل على الجهاز باستخدام MLS (IETF RFC 9420). |
| التخزين | لا تُخزَّن الرسائل على خوادم المنصة. |
| الهوية | محفظة EVM هي الهوية؛ ويُفعَّل الوضع بتوقيع واحد لا يتطلب رسوم غاز على كل جهاز. |
| المراجعة المستقلة | خضعت مكتبة libxmtp لتدقيق أجرته NCC Group. |

<Note>
  يحمي هذا الوضع محتوى الرسائل، لكنه لا يجعل المستخدمين مجهولي الهوية. ويسري التشفير على الرسائل الجديدة المُرسَلة في هذا الوضع.
</Note>

## روابط الإحالة

لكل مشارك رمز إحالة دائم. وتعتمد روابط الإحالة صيغة واحدة:

`share.rwanftfi.com/?ref=CODE`

لم تعد الصيغة القديمة للروابط تعمل: فقد استُبدلت في سبتمبر 2026 بسبب مشكلة في توصيل الروابط عبر Telegram.
