## ऑडिट विवरण

| आइटम | कहाँ सत्यापित करें |
|---|---|
| ऑडिटर | CertiK |
| रिपोर्ट तिथि | 28 अप्रैल 2026 |
| ऑडिट किया गया कमिट | सटीक हैश प्रकाशित रिपोर्ट में बताया गया है। |
| दायरे में कॉन्ट्रैक्ट्स | सभी समीक्षित कॉन्ट्रैक्ट्स प्रकाशित रिपोर्ट में सूचीबद्ध हैं। |
| निष्कर्ष | ID, गंभीरता, और स्थिति प्रकाशित रिपोर्ट में सूचीबद्ध हैं। |
| समाधान | प्रत्येक हल किया गया निष्कर्ष रिपोर्ट में संगत कोड परिवर्तन से लिंक है। |
| डिप्लॉयमेंट मैपिंग | क्या वर्तमान प्रोडक्शन कॉन्ट्रैक्ट्स ऑडिट किए गए संस्करण से मेल खाते हैं, यह अलग से प्रकाशित है। |
| बग बाउंटी | वर्तमान बाह्य रूप से सत्यापन योग्य स्थिति आधिकारिक चैनलों पर प्रकाशित है। |
