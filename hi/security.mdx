## ऑडिट विवरण

| मद | कहाँ सत्यापित करें |
|---|---|
| ऑडिटर | CertiK |
| रिपोर्ट की तिथि | 28 अप्रैल 2026 |
| ऑडिट किया गया कमिट | सटीक हैश प्रकाशित रिपोर्ट में दिया गया है। |
| दायरे में शामिल कॉन्ट्रैक्ट | सभी समीक्षित कॉन्ट्रैक्ट प्रकाशित रिपोर्ट में सूचीबद्ध हैं। |
| निष्कर्ष | ID, गंभीरता और स्थिति प्रकाशित रिपोर्ट में सूचीबद्ध हैं। |
| निवारण | रिपोर्ट में हल किया गया प्रत्येक निष्कर्ष संबंधित कोड परिवर्तन से जुड़ा है। |
| डिप्लॉयमेंट मैपिंग | वर्तमान प्रोडक्शन कॉन्ट्रैक्ट ऑडिट किए गए संस्करण से मेल खाते हैं या नहीं, यह अलग से प्रकाशित किया जाता है। |
| बग बाउंटी | वर्तमान, बाहरी रूप से सत्यापन योग्य स्थिति आधिकारिक चैनलों पर प्रकाशित की जाती है। |
