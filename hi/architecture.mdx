## Diamond Facets

| Facet | कार्य |
|---|---|
| AdminFacet | भूमिकाएँ, पैरामीटर, अनुमोदित स्थानांतरण, और विशेष NFT मिंटिंग। |
| MarketingFacet | पंजीकरण, NFT खरीद, और पार्टनर-रिवॉर्ड गणनाएँ। |
| FarmingFacet | NFTM माइनिंग और DA फार्मिंग। |
| PaymentFacet | जमा, निकासी, वाउचर, और बैलेंस स्थानांतरण। |
| TreeFacet | पार्टनर-नेटवर्क प्लेसमेंट और गहराई। |
| ResolverFacet | समाप्त मान, वाउचर प्रोसेसिंग, और फ्रोजन बैलेंस समाधान। |
| ViewFacet | केवल-पढ़ने योग्य उपयोगकर्ता, बैलेंस, और नेटवर्क क्वेरी। |

## NFT कॉन्ट्रैक्ट्स

- Regular NFTs विषम टोकन ID का उपयोग करते हैं।
- Gift NFTs सम टोकन ID का उपयोग करते हैं।
- Ambassador NFTs एक अलग कॉन्ट्रैक्ट और कॉन्फ़िगरेशन का उपयोग करते हैं।

## अपग्रेडेबिलिटी मैट्रिक्स

| घटक | मॉडल |
|---|---|
| Diamond Contract | फ़ेसेट कट्स के माध्यम से अपग्रेड योग्य। |
| TokenReserve / DA | दस्तावेज़ीकृत प्रॉक्सी तंत्र के माध्यम से अपग्रेड योग्य। |
| NFT Contracts | गैर-अपग्रेड योग्य के रूप में दस्तावेज़ीकृत। |
| GovToken | निश्चित आपूर्ति के साथ गैर-अपग्रेड योग्य के रूप में दस्तावेज़ीकृत। |
| AdminContract | गैर-अपग्रेड योग्य के रूप में दस्तावेज़ीकृत। |

## भूमिका प्रबंधन

| भूमिका | दस्तावेज़ीकृत अधिकार |
|---|---|
| `ADMIN_ROLE` | भूमिकाएँ प्रदान और रद्द करना; अनुमत प्रोटोकॉल पैरामीटर बदलना। |
| `SERVICE_ROLE` | दस्तावेज़ीकृत स्वचालित और क्रॉस-चेन सेवा संचालन निष्पादित करना। |
| `SIGNER_ROLE` | निर्दिष्ट कार्रवाइयों के लिए अधिकृत हस्ताक्षर सत्यापित करना। |
| `MINTER_ROLE` | उस भूमिका को सौंपे गए टोकन या NFT प्रकार को मिंट करना। |

## बैलेंस स्कीमा

| बैलेंस | उद्देश्य |
|---|---|
| Regular Balance | योग्य निकासी, खरीद, और वाउचर। |
| Accumulative Balance | दस्तावेज़ीकृत खरीद, स्थानांतरण, शुल्क, और पुनर्वितरण नियमों के तहत उपयोग किया जाने वाला एक प्रतिबंधित आंतरिक बैलेंस। |
| प्रोटोकॉल रिवॉर्ड कैप | सक्रिय NFT चक्र के लिए शेष रिवॉर्ड पात्रता; ऑन-चेन शब्द: *Income Limit*। |
| Token Reserve Balance | DA मैकेनिक्स का समर्थन करने वाला नामित लिक्विडिटी-पूल बैलेंस। |
| Dev Balance | प्रोटोकॉल और परिचालन आवंटन। |
| Price Impact Balance | दस्तावेज़ीकृत प्राइस-इम्पैक्ट फ़ंक्शन द्वारा उपयोग किया जाने वाला रिज़र्व। |
