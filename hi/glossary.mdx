RWANFTFI दस्तावेज़ीकरण में उपयोग किए गए शब्दों के लिए सत्य का एकल स्रोत।

| शब्द | परिभाषा |
|---|---|
| **Accumulative Balance** | योग्य पार्टनर रिवॉर्ड्स के कॉन्फ़िगर किए गए हिस्से को प्राप्त करने वाला एक प्रतिबंधित आंतरिक बैलेंस। |
| **ऑटो-सेल (Auto-Sell)** | चार प्रोटोकॉल अवधियों में शेष DA का निर्धारित प्रोसेसिंग। |
| **Autobuy** | जब किसी योग्य NFT का प्रोटोकॉल रिवॉर्ड कैप समाप्त हो जाता है, तो उसका स्वचालित नवीनीकरण। |
| **DA** | अधिकतम 21,000,000 इकाइयों की आपूर्ति वाला एक गैर-हस्तांतरणीय BEP-20 प्रोटोकॉल यूटिलिटी टोकन। |
| **फ्रोजन बैलेंस (Frozen Balance)** | शेष प्रोटोकॉल रिवॉर्ड कैप से अधिक किसी योग्य Sponsor Bonus के लिए एक अस्थायी 72-घंटे का बफ़र। |
| **GovToken** | स्थायी रूप से निश्चित आपूर्ति वाला ERC20Votes गवर्नेंस टोकन। |
| **Matching Bonus** | तीन योग्य स्तरों तक का एक सशर्त रिवॉर्ड। |
| **Missed Reward** | वह गतिविधि जो क्रेडिट नहीं हुई क्योंकि लागू पात्रता शर्तें पूरी नहीं हुईं। |
| **NFTM** | फार्मिंग गणना में उपयोग किया जाने वाला एक आंतरिक माइनिंग काउंटर। |
| **पार्टनर नेटवर्क (Partner Network)** | स्मार्ट-कॉन्ट्रैक्ट द्वारा प्रबंधित एक संरचना जो प्लेसमेंट और रिवॉर्ड पात्रता को परिभाषित करने के लिए उपयोग होती है। |
| **पार्टनर नेटवर्क डेप्थ (Partner Network Depth)** | योग्य वितरण गणनाओं में शामिल अधिकतम नेटवर्क गहराई। |
| **प्रोटोकॉल रिवॉर्ड कैप (Protocol Reward Cap)** | NFT चक्र के दौरान क्रेडिट किए गए अधिकतम संचयी योग्य रिवॉर्ड्स; ऑन-चेन शब्द: *Income Limit*। |
| **Sponsor Bonus** | किसी योग्य प्रत्यक्ष NFT खरीद से प्राप्त सशर्त रिवॉर्ड। |
| **Tree Distribution** | Partner Network Distribution के लिए ऑन-चेन नाम — योग्य नेटवर्क गहराई के भीतर प्रति-स्तर प्रोटोकॉल रिवॉर्ड गणना। |
