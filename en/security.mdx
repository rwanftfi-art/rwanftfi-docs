## Four Layers of Account Security

<CardGroup cols={2}>
  <Card title="Financial Password" icon="fingerprint">
    A password separate from login credentials, required for financial actions.
  </Card>
  <Card title="Secret Code" icon="user-lock" href="/en/platform-features#secret-code">
    A random word generated with the financial password. Required for any security-related request to support.
  </Card>
  <Card title="Transaction Authorization Codes" icon="key">
    Single-use codes required to authorize financial transactions.
  </Card>
  <Card title="Two-Factor Authentication" icon="lock">
    Supported two-factor authentication for account protection.
  </Card>
</CardGroup>
