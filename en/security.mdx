## Smart Contract Security

Security is embedded across multiple levels within the platform. All logic and distribution algorithms are locked in immutable code, ensuring 100% transparency. System evolution is managed collectively via the DAO, removing centralized points of failure.

## CertiK Audit

The smart contracts have passed a comprehensive independent audit by **CertiK**, a leading Web3 security firm. This audit verified the architecture, assessed vulnerabilities, and confirmed logic correctness.

## Account Protection

The platform employs a robust multi-layer protection system for user accounts, including a three-level security system, Transaction Authentication Number (TAN) codes, a separate financial password, standard Two-Factor Authentication (2FA), and Telegram Bot verification.

<Info>
  While users can log into the web dashboard with email/password to view data, executing any financial transaction **requires** a connected Web3 wallet (MetaMask, Trust Wallet, etc.).
</Info>
