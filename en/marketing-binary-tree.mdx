The partner network is the protocol's placement registry — an on-chain data structure that records where each account sits and which network relationships are included in reward calculations. When an eligible NFT is activated, the account receives a permanent position. Placement, network depth, and reward eligibility follow the active protocol rules.

## How does placement work?

<Steps>
  <Step title="First-level positions fill first">
    The first direct registrations fill the available first-level positions.
  </Step>
  <Step title="The algorithm places the rest">
    Additional registrations are placed under the branch selected by the documented weakest-branch algorithm.
  </Step>
  <Step title="Automated placement can cross accounts">
    The algorithm may record a participant inside another user's network (spillover). This is a bookkeeping outcome of automated placement, not a reward event.
  </Step>
  <Step title="Placement alone does not create a reward">
    Reward eligibility depends on tier, depth, qualifying activity, the active phase, and remaining Protocol Reward Cap.
  </Step>
</Steps>

## Network Depth in Reward Calculations

Each NFT tier defines the maximum network depth included in eligible Partner Network Distribution calculations. Current Phase 1 values are shown in the [NFT tier table](/en/nft-ecosystem#all-10-tiers-at-a-glance). Levels 16–22 require the documented governance activation.

## Structural Capacity

The registry is a bounded binary structure with a documented maximum depth of 22 levels — a fixed technical capacity of 8,388,606 positions, excluding the root position. This figure is a property of the data structure, not a participation target or a projection.
