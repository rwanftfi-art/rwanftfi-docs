Uma fonte única de verdade para os termos utilizados em toda a documentação da RWANFTFI.

| Termo | Definição |
|---|---|
| **Saldo Acumulativo** | Saldo interno restrito que recebe a parcela configurada das recompensas elegíveis de parceiros. |
| **Auto-Sell** | Processamento programado do DA restante ao longo de quatro períodos do protocolo. |
| **Autobuy** | Renovação automática de um NFT elegível quando seu Limite de Recompensas do Protocolo se esgota. |
| **DA** | Token de utilidade do protocolo, não transferível, do padrão BEP-20, com oferta máxima de 21.000.000 de unidades. |
| **Frozen Balance** | Buffer temporário de 72 horas para um Bônus de Patrocinador elegível acima do Limite de Recompensas do Protocolo restante. |
| **GovToken** | Token de governança ERC20Votes de oferta fixa. |
| **Matching Bonus** | Recompensa condicional distribuída em até três níveis elegíveis. |
| **Renda Perdida** | Atividade não creditada porque as condições de elegibilidade aplicáveis não foram atendidas. |
| **NFTM** | Contador interno de Mineração utilizado no cálculo do Farming. |
| **Rede de Parceiros** | Estrutura gerenciada pelo smart contract, utilizada para definir o posicionamento e a elegibilidade de recompensas. |
| **Profundidade da Rede de Parceiros** | Profundidade máxima da rede incluída nos cálculos elegíveis de distribuição. |
| **Limite de Recompensas do Protocolo** | Máximo cumulativo de recompensas elegíveis creditadas durante um ciclo de NFT; termo on-chain: *Income Limit*. |
| **Bônus de Patrocinador** | Recompensa condicional proveniente de uma compra direta elegível de NFT. |
| **Distribuição em Árvore** | Nome on-chain para a Distribuição da Rede de Parceiros — o cálculo de recompensa do protocolo por nível, dentro da profundidade elegível da rede. |
