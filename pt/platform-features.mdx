## Secret Code

O Secret Code é uma palavra aleatória gerada junto com a senha financeira. Ele é obrigatório para qualquer solicitação ao suporte relacionada à segurança: sem ele, o suporte não pode dar andamento a esse tipo de solicitação.

<Warning>
  **Mantenha o Secret Code em sigilo.** Compartilhe-o somente com o suporte oficial, e somente quando fizer uma solicitação de segurança. Nunca o compartilhe em chats, comentários ou mensagens privadas.
</Warning>

## Mensageiro e chats Web3 privados

O mensageiro integrado mostra o horário exato de cada mensagem. Nele, o modo **Private Web3 chats** adiciona criptografia de ponta a ponta no protocolo XMTP.

| Propriedade | Como funciona |
|---|---|
| Criptografia | As mensagens são criptografadas no dispositivo com MLS (IETF RFC 9420). |
| Armazenamento | As mensagens não são armazenadas nos servidores da plataforma. |
| Identidade | A carteira EVM é a identidade; uma assinatura sem gas por dispositivo ativa o modo. |
| Revisão independente | A biblioteca libxmtp foi auditada pelo NCC Group. |

<Note>
  O modo protege o conteúdo das mensagens; ele não torna os usuários anônimos. A criptografia se aplica às novas mensagens enviadas nesse modo.
</Note>

## Links de indicação

Cada participante tem um código de indicação permanente. Os links de indicação usam um único formato:

`share.rwanftfi.com/?ref=CODE`

O formato antigo de link não funciona mais: ele foi substituído em setembro de 2026 devido a um problema na entrega de links no Telegram.
