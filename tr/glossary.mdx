RWANFTFI belgelerinde kullanılan terimler için tek doğru kaynak.

| Terim | Tanım |
|---|---|
| **Birikim Bakiyesi** | Uygun partner ödüllerinin yapılandırılmış payını alan kısıtlı dahili bakiye. Kullanılmayan fonlar, bakiye ömrü sona erdikten sonra yeniden dağıtıma uygun hale gelir; bu süre şu anda 180 gündür (DAO oylamasıyla geçici olarak uzatılmıştır). |
| **Otomatik Satış** | Kalan DA'nın dört protokol dönemi boyunca planlı olarak işlenmesi. |
| **Otomatik Alım** | Protokol Ödül Limiti tükendiğinde uygun bir NFT'nin otomatik olarak yenilenmesi. |
| **DA** | Maksimum arzı 21.000.000 birim olan, transfer edilemeyen BEP-20 protokol yardımcı tokeni. |
| **Dondurulmuş Bakiye** | Kalan Protokol Ödül Limitini aşan nitelikli bir Sponsor Bonusu için geçici 72 saatlik tampon. |
| **GovToken** | Sabit arzlı ERC20Votes yönetişim tokeni. |
| **Eşleştirme Bonusu** | En fazla üç nitelikli seviyede uygulanan koşullu ödül. |
| **Kayıp Ödül** | Geçerli uygunluk koşulları karşılanmadığı için hesaba yansıtılmayan faaliyet. |
| **NFTM** | Farming hesaplamasında kullanılan dahili Madencilik sayacı. |
| **Partner Ağı** | Yerleştirmeyi ve ödül uygunluğunu tanımlamak için kullanılan, akıllı sözleşme tarafından yönetilen yapı. |
| **Partner Ağı Derinliği** | Uygun dağıtım hesaplamalarına dahil edilen maksimum ağ derinliği. |
| **Protokol Ödül Limiti** | Bir NFT döngüsü boyunca yatırılan maksimum kümülatif uygun ödüller; zincir üzerindeki terim: *Income Limit*. |
| **Sponsor Bonusu** | Nitelikli bir doğrudan NFT satın alımından doğan koşullu ödül. |
| **Ağaç Dağılımı** | Uygun ağ derinliği dahilinde seviye başına partner ödülü hesaplaması. |
