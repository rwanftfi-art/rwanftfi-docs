RWANFTFI belgeleri genelinde kullanılan terimler için tek doğru kaynak.

| Terim | Tanım |
|---|---|
| **Birikim Bakiyesi** | Uygun ortak ödüllerinin yapılandırılmış payını alan kısıtlı dahili bakiye. |
| **Auto-Sell** | Kalan DA'nın dört protokol dönemi boyunca planlanmış işlenmesi. |
| **Autobuy** | Protokol Ödül Limiti tükendiğinde uygun bir NFT'nin otomatik olarak yenilenmesi. |
| **DA** | En fazla 21.000.000 birim arzına sahip, transfer edilemeyen BEP-20 protokol yardımcı programı tokeni. |
| **Frozen Balance** | Kalan Protokol Ödül Limitinin üzerindeki uygun bir Sponsor Bonusu için geçici 72 saatlik tampon. |
| **GovToken** | Sabit arzlı ERC20Votes yönetişim tokeni. |
| **Matching Bonus** | En fazla üç uygun seviye boyunca koşullu ödül. |
| **Kaçırılan Ödül** | Geçerli uygunluk koşulları karşılanmadığı için alacaklandırılmayan etkinlik. |
| **NFTM** | Farming hesaplamasında kullanılan dahili Madencilik sayacı. |
| **Ortak Ağı** | Yerleştirme ve ödül uygunluğunu tanımlamak için kullanılan, akıllı sözleşme tarafından yönetilen yapı. |
| **Ortak Ağı Derinliği** | Uygun dağıtım hesaplamalarına dahil edilen maksimum ağ derinliği. |
| **Protokol Ödül Limiti** | Bir NFT döngüsü sırasında alacaklandırılan maksimum kümülatif uygun ödül; zincir üzerindeki (on-chain) terim: *Income Limit*. |
| **Sponsor Bonusu** | Uygun bir doğrudan NFT satın alımından elde edilen koşullu ödül. |
| **Ağaç Dağılımı** | Ortak Ağı Dağıtımının zincir üzerindeki (on-chain) adı — uygun ağ derinliği içindeki seviye başına protokol ödülü hesaplaması. |
