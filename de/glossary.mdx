Eine einzige Wahrheitsquelle für die in der gesamten RWANFTFI-Dokumentation verwendeten Begriffe.

| Begriff | Definition |
|---|---|
| **Akkumulatives Guthaben** | Eingeschränktes internes Guthaben, das den konfigurierten Anteil berechtigter Partner-Belohnungen erhält. |
| **Auto-Sell** | Planmäßige Verarbeitung des verbleibenden DA über vier Protokollperioden. |
| **Autobuy** | Automatische Erneuerung eines berechtigten NFTs, wenn dessen Protokoll-Belohnungslimit erschöpft ist. |
| **DA** | Nicht übertragbarer BEP-20-Protokoll-Utility-Token mit einem maximalen Angebot von 21.000.000 Einheiten. |
| **Frozen Balance** | Temporärer 72-Stunden-Puffer für einen qualifizierenden Sponsor-Bonus oberhalb des verbleibenden Protokoll-Belohnungslimits. |
| **GovToken** | Governance-Token mit fixem Angebot (ERC20Votes). |
| **Matching Bonus** | Bedingte Belohnung über bis zu drei qualifizierende Ebenen. |
| **Verpasste Belohnung** | Aktivität, die nicht angerechnet wurde, weil die geltenden Berechtigungsbedingungen nicht erfüllt waren. |
| **NFTM** | Interner Mining-Zähler, der in der Farming-Berechnung verwendet wird. |
| **Partnernetzwerk** | Vom Smart Contract verwaltete Struktur zur Definition von Platzierung und Belohnungsberechtigung. |
| **Partnernetzwerk-Tiefe** | Maximale Netzwerktiefe, die in berechtigte Verteilungsberechnungen einbezogen wird. |
| **Protokoll-Belohnungslimit** | Maximale kumulative berechtigte Belohnungen, die während eines NFT-Zyklus angerechnet werden; On-Chain-Begriff: *Income Limit*. |
| **Sponsor-Bonus** | Bedingte Belohnung aus einem qualifizierenden direkten NFT-Kauf. |
| **Tree Distribution** | On-Chain-Name für die Partnernetzwerk-Verteilung – die Berechnung der Protokoll-Belohnung pro Ebene innerhalb der berechtigten Netzwerktiefe. |
