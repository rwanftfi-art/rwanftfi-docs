## Sicherheitshinweise

<Warning>
  - Geben Sie niemals eine Seed-Phrase, einen privaten Schlüssel, ein Finanzpasswort, einen TAN-Code oder einen Code der Zwei-Faktor-Authentifizierung weiter.
  - Geben Sie Ihren **Secret Code** ausschließlich an den offiziellen Support weiter und nur im Rahmen einer sicherheitsbezogenen Anfrage. Ohne ihn kann der Support eine Sicherheitsanfrage nicht bearbeiten.
  - Der Support schreibt Sie niemals zuerst an und fragt niemals nach einer Seed-Phrase, einem privaten Schlüssel oder einer Vorauszahlung, um Mittel oder ein Konto „freizuschalten“. Jede solche Anfrage ist Betrug.
  - Gleichen Sie die Domain mit der [Liste der offiziellen Domains](/de/security#offizielle-domains) ab und prüfen Sie die Vertragsadressen.
  - Melden Sie Identitätsbetrug und Phishing über den offiziellen Sicherheitskontakt.
</Warning>
