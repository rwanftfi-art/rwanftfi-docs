## Sponsor-Bonus

Der Sponsor-Bonus wird aus einem qualifizierenden direkten NFT-Kauf berechnet. Die aktuellen Sätze gelten, seit Phase 2 im Juni 2026 per DAO-Abstimmung aktiviert wurde.

<CardGroup cols={2}>
  <Card title="20 %" icon="user-plus">
    **Erstkauf.** Gilt für den ersten NFT-Kauf eines persönlich eingeladenen Partners.
  </Card>
  <Card title="17 % + 1–5 %" icon="rotate">
    **Wiederholungskauf.** Ein Basissatz von 17 % plus 1–5 %, abhängig von der Ebene, auf der dieser Partner in Ihrem Partnernetzwerk platziert ist.
  </Card>
</CardGroup>

## Tree Distribution

| Netzwerkebene | Aktueller Satz |
|:---:|:---:|
| 1 | 0 % |
| 2 | 1 % |
| 3–4 | je 2 % |
| 5–6 | je 3 % |
| 7–14 | je 4 % |
| 15 | 5 % |
| 16–22 | 0 % bis zur Aktivierung durch die Governance |

## Matching-Bonus

| Matching-Ebene | Satz | Berechtigung |
|:---:|:---:|---|
| 1 | 5 % | Berechtigte NFT-Stufe |
| 2 | 5 % | 1.000 USDT kumulative persönliche Verkäufe |
| 3 | 5 % | 3.000 USDT kumulative persönliche Verkäufe |

## Standardaufteilung der Belohnungen

Qualifizierte Partnerbelohnungen werden derzeit gemäß der dokumentierten **75/20/5**-Allokation auf das Reguläre Guthaben, das Akkumulative Guthaben und den DA-Liquiditätspool aufgeteilt.

## Kompression

Erfüllt eine Netzwerkposition die geltenden Berechtigungsbedingungen nicht, wird der Betrag gemäß den aktiven Regeln zu Kompression und Restbudget weitergeleitet. Die genaue Weiterleitung entspricht den aktuellen Vertragsparametern — siehe [Vertragsparameter](/de/contract-parameters).
