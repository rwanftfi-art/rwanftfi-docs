## Secret Code

Der Secret Code ist ein zufälliges Wort, das zusammen mit dem Finanzpasswort generiert wird. Er ist für jede sicherheitsbezogene Anfrage an den Support erforderlich: Ohne ihn kann der Support eine solche Anfrage nicht bearbeiten.

<Warning>
  **Halten Sie den Secret Code geheim.** Geben Sie ihn ausschließlich an den offiziellen Support weiter und nur dann, wenn Sie eine Sicherheitsanfrage stellen. Teilen Sie ihn niemals in Chats, Kommentaren oder Privatnachrichten.
</Warning>

## Messenger und private Web3-Chats

Der integrierte Messenger zeigt die genaue Uhrzeit jeder Nachricht an. Der Modus **Private Web3 chats** ergänzt ihn um eine Ende-zu-Ende-Verschlüsselung auf Basis des XMTP-Protokolls.

| Eigenschaft | Funktionsweise |
|---|---|
| Verschlüsselung | Nachrichten werden auf dem Gerät mit MLS (IETF RFC 9420) verschlüsselt. |
| Speicherung | Nachrichten werden nicht auf den Servern der Plattform gespeichert. |
| Identität | Die EVM-Wallet dient als Identität; eine einzige Signatur ohne Gasgebühr pro Gerät aktiviert den Modus. |
| Unabhängige Prüfung | Die Bibliothek libxmtp wurde von der NCC Group auditiert. |

<Note>
  Der Modus schützt den Inhalt der Nachrichten, macht Nutzer jedoch nicht anonym. Die Verschlüsselung gilt für neue Nachrichten, die in diesem Modus gesendet werden.
</Note>

## Empfehlungslinks

Jeder Teilnehmer hat einen dauerhaften Empfehlungscode. Empfehlungslinks haben ein einheitliches Format:

`share.rwanftfi.com/?ref=CODE`

Das alte Linkformat funktioniert nicht mehr: Es wurde im August 2026 wegen eines Problems bei der Zustellung von Links in Telegram ersetzt.
