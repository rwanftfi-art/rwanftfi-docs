## Consignes de Sécurité

<Warning>
  - Ne communiquez jamais une phrase seed, une clé privée, un mot de passe financier, un code TAN ou un code d'authentification à deux facteurs.
  - Vérifiez le domaine officiel et l'adresse du contrat.
  - Signalez les usurpations d'identité et l'hameçonnage via le contact de sécurité officiel.
</Warning>
