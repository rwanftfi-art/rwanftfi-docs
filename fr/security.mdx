## Détails de l'Audit

| Élément | Où Vérifier |
|---|---|
| Auditeur | CertiK |
| Date du rapport | 28 avril 2026 |
| Commit audité | Le hash exact est indiqué dans le rapport publié. |
| Contrats dans le périmètre | Tous les contrats revus sont répertoriés dans le rapport publié. |
| Constats | L'ID, la gravité et le statut sont indiqués dans le rapport publié. |
| Correction | Chaque constat résolu est lié à la modification de code correspondante dans le rapport. |
| Correspondance des déploiements | La correspondance éventuelle entre les contrats de production actuels et la version auditée est publiée séparément. |
| Bug bounty | Le statut actuel, vérifiable de l'extérieur, est publié sur les canaux officiels. |

## Protection contre l'Hameçonnage

<Warning>
  Utilisez uniquement les domaines et les adresses de contrat officiels de RWANFTFI. Les représentants de RWANFTFI ne doivent jamais demander de clés privées, de phrases seed ni de paiements vers des adresses de wallet non officielles. Vérifiez toujours que vous êtes sur **rwanftfi.com** avant de connecter votre wallet ou de saisir vos identifiants.
</Warning>
