## Secret Code

Le Secret Code est un mot aléatoire généré en même temps que le mot de passe financier. Il est obligatoire pour toute demande au support liée à la sécurité : sans lui, le support ne peut pas donner suite à une telle demande.

<Warning>
  **Gardez le Secret Code confidentiel.** Ne le communiquez qu'au support officiel, et uniquement lorsque vous soumettez une demande liée à la sécurité. Ne le partagez jamais dans des chats, des commentaires ou des messages privés.
</Warning>

## Messagerie et chats Web3 privés

La messagerie intégrée affiche l'heure exacte de chaque message. Son mode **Private Web3 chats** ajoute le chiffrement de bout en bout sur le protocole XMTP.

| Propriété | Fonctionnement |
|---|---|
| Chiffrement | Les messages sont chiffrés sur l'appareil avec MLS (IETF RFC 9420). |
| Stockage | Les messages ne sont pas stockés sur les serveurs de la plateforme. |
| Identité | Le wallet EVM sert d'identité ; une signature sans frais de gaz par appareil active le mode. |
| Revue indépendante | La bibliothèque libxmtp a été auditée par NCC Group. |

<Note>
  Le mode protège le contenu des messages ; il ne rend pas les utilisateurs anonymes. Le chiffrement s'applique aux nouveaux messages envoyés dans ce mode.
</Note>

## Liens de parrainage

Chaque participant dispose d'un code de parrainage permanent. Les liens de parrainage utilisent un format unique :

`share.rwanftfi.com/?ref=CODE`

L'ancien format de lien ne fonctionne plus : il a été remplacé en septembre 2026 en raison d'un problème de transmission des liens dans Telegram.
