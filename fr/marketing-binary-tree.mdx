## Comment Fonctionne le Placement
<Steps>
  <Step title="Vous Invitez">
    Vos 2 premières invitations remplissent votre Niveau 1 (position gauche et droite).
  </Step>
  <Step title="L'Arbre Pousse vers le Bas">
    Les invitations suivantes vont au Niveau 2 sous la branche la plus faible.
    Votre structure croît exponentiellement : 2 → 4 → 8 → 16 positions par niveau.
  </Step>
  <Step title="Le Spillover Comble les Vides">
    Lorsque vos sponsors amont invitent plus de personnes que leur Niveau 1 ne peut en accueillir,
    ces utilisateurs débordent dans VOTRE arbre. Vous gagnez automatiquement grâce à eux.
  </Step>
  <Step title="Vous Gagnez en Profondeur">
    Le niveau de votre NFT détermine la profondeur jusqu'à laquelle vous gagnez.
    GENESIS gagne sur 2 niveaux. INFINITY gagne jusqu'à 22 niveaux
    (les niveaux 16–22 se débloquent en Phase 2 via un vote de gouvernance DAO).
  </Step>
</Steps>

<Info>
  **Le multi-comptes est strictement interdit.** Le système applique
  une politique d'un utilisateur, un compte avec un suivi intégré.
</Info>
<Warning>
  **Le sponsor est permanent.** Une fois placé dans l'arbre, votre sponsor
  ne peut pas être changé. Choisissez avec soin avant d'activer votre NFT.
</Warning>

<Info>
  **Le sponsor doit être un nœud actif de l'arbre.** Lorsqu'un nouvel utilisateur est enregistré via `registerUser()`, le smart contract n'accepte aucun ID utilisateur existant comme sponsor — le sponsor fourni doit être un **nœud actif dans la structure marketing**. Concrètement, le sponsor doit :

  - Détenir un **NFT actif** dans le système, et
  - Être **enregistré dans l'arbre** comme un nœud vivant (tree node active).

  Un **mappage uniquement d'identité** — un wallet auquel un ID utilisateur a été attribué mais qui ne détient pas actuellement de NFT actif — ne peut plus parrainer de nouvelles invitations. Cela empêche les nouveaux participants d'être placés sous des sponsors inactifs, bloque la création de branches mortes dans la structure et préserve l'intégrité du flux de récompenses de chaque sous-arbre.
</Info>
