Une source de vérité unique pour les termes utilisés dans l'ensemble de la documentation RWANFTFI.

| Terme | Définition |
|---|---|
| **Solde Cumulatif** | Solde interne restreint recevant la part configurée des récompenses partenaires éligibles. |
| **Auto-Sell** | Traitement programmé du DA restant sur quatre périodes protocolaires. |
| **Autobuy** | Renouvellement automatique d'un NFT éligible lorsque son Plafond de Récompenses du Protocole est épuisé. |
| **DA** | Jeton utilitaire protocolaire BEP-20 non transférable avec une offre maximale de 21 000 000 unités. |
| **Frozen Balance** | Tampon temporaire de 72 heures pour un Bonus de Sponsor qualifiant dépassant le Plafond de Récompenses du Protocole restant. |
| **GovToken** | Jeton de gouvernance ERC20Votes à offre fixe. |
| **Matching Bonus** | Récompense conditionnelle sur jusqu'à trois niveaux qualifiants. |
| **Revenu Perdu** | Activité non créditée parce que les conditions d'éligibilité applicables n'ont pas été remplies. |
| **NFTM** | Compteur de Mining interne utilisé dans le calcul du Farming. |
| **Réseau de Partenaires** | Structure gérée par le smart contract, utilisée pour définir le placement et l'éligibilité aux récompenses. |
| **Profondeur du Réseau de Partenaires** | Profondeur maximale de réseau incluse dans les calculs de distribution éligibles. |
| **Plafond de Récompenses du Protocole** | Montant cumulatif maximal de récompenses éligibles créditées pendant un cycle de NFT ; terme on-chain : *Income Limit*. |
| **Bonus de Sponsor** | Récompense conditionnelle issue d'un achat direct de NFT qualifiant. |
| **Distribution de l'Arbre** | Calcul de récompense partenaire par niveau à l'intérieur de la profondeur de réseau éligible. |
