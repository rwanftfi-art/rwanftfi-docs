## Лимит дохода и автообновление

<AccordionGroup>
  <Accordion title="Как работает лимит дохода" icon="gauge-high">
    Каждый NFT имеет строгий лимит дохода. Как только маркетинговые вознаграждения достигают этого лимита, он обнуляется и вы пропускаете все дальнейшие награды. Обновите NFT, чтобы этого избежать. Ручная перепокупка невозможна при остатке лимита выше 30%.
  </Accordion>
  <Accordion title="Autobuy (система 3/3)" icon="rotate">
    Для всех NFT кроме Elite (L9–L10) активируйте Autobuy — автоматическая перепокупка того же NFT до 3 раз при обнулении лимита. Требуется достаточно USDT на балансе. Сбрасывается до 3/3 при апгрейде.
  </Accordion>
  <Accordion title="Продажа бизнеса" icon="handshake">
    Продайте всю бизнес-структуру (дерево партнёров) другому пользователю через DAO. Комиссия: 500 USDT (регулируется DAO). Продажа отдельного NFT без структуры невозможна.
  </Accordion>
</AccordionGroup>

<Warning>
  Лимит дохода: Когда лимит NFT исчерпан, вы перестаёте получать ВСЕ маркетинговые вознаграждения. Включите Autobuy или обновите NFT вручную при остатке ниже 30%.
</Warning>
