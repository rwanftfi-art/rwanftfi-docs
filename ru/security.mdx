## Защита аккаунта

Аудит покрывает on-chain слой смарт-контракта. На уровне приложения аккаунты пользователей дополнительно защищены несколькими независимыми механизмами:

<CardGroup cols={2}>
  <Card title="Трёхуровневая безопасность" icon="layer-group">
    Многослойная защита: вход в систему, финансовые действия и операции с высокой стоимостью разделены на отдельные уровни.
  </Card>
  <Card title="TAN-коды" icon="key">
    Одноразовые коды аутентификации транзакций (Transaction Authentication Numbers), требуемые для каждой финансовой операции.
  </Card>
  <Card title="Финансовый пароль" icon="lock">
    Отдельный от пароля входа, требуется только для движения средств.
  </Card>
  <Card title="2FA + Telegram-бот" icon="telegram">
    Стандартная двухфакторная аутентификация и подтверждение действий через официальный Telegram-бот.
  </Card>
</CardGroup>

<Info>
  **Транзакции требуют Web3-кошелька.** Войти в дашборд для просмотра данных можно по email и паролю, но выполнение любой финансовой операции требует подключённого Web3-кошелька (MetaMask, Trust Wallet или другой EVM-совместимый).
</Info>
