## Secret Code

Secret Code — случайное слово, которое генерируется вместе с финансовым паролем. Он обязателен для любого запроса в службу поддержки, связанного с безопасностью: без него поддержка не может выполнить такой запрос.

<Warning>
  **Храните Secret Code в тайне.** Сообщайте его только официальной службе поддержки и только при запросе по безопасности. Никогда не публикуйте его в чатах, комментариях или личных сообщениях.
</Warning>

## Мессенджер и приватные Web3-чаты

Встроенный мессенджер показывает точное время каждого сообщения. Режим **Private Web3 chats** добавляет сквозное шифрование на протоколе XMTP.

| Свойство | Как это работает |
|---|---|
| Шифрование | Сообщения шифруются на устройстве по протоколу MLS (IETF RFC 9420). |
| Хранение | Сообщения не хранятся на серверах платформы. |
| Идентификация | Идентификатором служит EVM-кошелёк; одна подпись без газа на каждом устройстве включает режим. |
| Независимая проверка | Библиотека libxmtp прошла аудит NCC Group. |

<Note>
  Режим защищает содержание сообщений, но не делает пользователей анонимными. Шифрование применяется к новым сообщениям, отправленным в этом режиме.
</Note>

## Реферальные ссылки

У каждого участника постоянный реферальный код. Реферальные ссылки имеют единый формат:

`share.rwanftfi.com/?ref=CODE`

Старый формат ссылок больше не работает: его заменили в сентябре 2026 года из-за проблемы с доставкой ссылок в Telegram.
