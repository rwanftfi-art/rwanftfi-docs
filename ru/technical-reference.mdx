<AccordionGroup>
  <Accordion title="Accumulative Event" icon="clock">
    30-дневный период (с кулдауном 180 дней), инициируемый через DAO, в течение которого пользователи могут заявить права на истёкшие накопительные балансы.
  </Accordion>
  <Accordion title="ADMIN_ROLE" icon="user-shield">
    Роль с правами управления системными параметрами и предоставления доступа.
  </Accordion>
  <Accordion title="Diamond Pattern (EIP-2535)" icon="diamond">
    Архитектурный паттерн смарт-контрактов, обходящий лимит размера 24KB путём разделения логики на модули (Facets).
  </Accordion>
  <Accordion title="Freeze" icon="snowflake">
    Механизм модерации, инициируемый исключительно через голосование DAO, блокирующий все финансовые операции для конкретного аккаунта пользователя. Используется для соблюдения политики, а не как экстренный инструмент безопасности. Как заморозка, так и разморозка требуют голосования DAO.
  </Accordion>
  <Accordion title="freezeTime" icon="hourglass">
    Параметр, определяющий длительность заморозки аккаунта при блокировке через DAO.
  </Accordion>
  <Accordion title="GovToken" icon="landmark">
    Токен управления ERC20Votes (объём 10M, 6 десятичных знаков), используемый для голосования DAO, с автоделегацией и отключённой ручной делегацией.
  </Accordion>
  <Accordion title="LibSignatureLogic" icon="signature">
    Библиотека смарт-контрактов для верификации криптографических подписей с использованием SIGNER_ROLE.
  </Accordion>
  <Accordion title="Price Impact Event" icon="chart-line">
    Механизм управления стабильностью цены DA через специальный резервный баланс (priceImpactBalance).
  </Accordion>
  <Accordion title="processExpiredStacks" icon="rotate">
    Функция ResolverFacet для обработки DA-стеков, периоды разблокировки которых полностью истекли.
  </Accordion>
  <Accordion title="SERVICE_ROLE" icon="server">
    Роль смарт-контракта для автоматизированных бэкенд-операций — обработка кросс-чейн депозитов и разрешение истёкших стеков.
  </Accordion>
  <Accordion title="SIGNER_ROLE" icon="key">
    Роль для криптографической верификации подписей при авторизации операций, таких как передача ваучеров.
  </Accordion>
  <Accordion title="TokenStack" icon="layer-group">
    Структура данных смарт-контракта, хранящая токены DA пользователя и отслеживающая прогрессивные периоды разблокировки по времени (25%, 40%, 50%, 100%) для продажи.
  </Accordion>
  <Accordion title="Transparent Proxy" icon="arrows-rotate">
    Паттерн обновления контракта TokenReserve (DA), позволяющий обновлять логику без смены адреса контракта.
  </Accordion>
</AccordionGroup>
