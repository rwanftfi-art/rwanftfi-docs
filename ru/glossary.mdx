Единый источник истины для терминов, используемых в документации RWANFTFI.

| Термин | Определение |
|---|---|
| **Накопительный баланс** | Ограниченный внутренний баланс, получающий настроенную долю квалифицируемых партнёрских вознаграждений. |
| **Auto-Sell** | Плановая обработка оставшегося DA за четыре протокольных периода. |
| **Autobuy (автопокупка)** | Автоматическое продление подходящего NFT при исчерпании его Лимита вознаграждений протокола. |
| **DA** | Непередаваемый служебный токен протокола стандарта BEP-20 с максимальным предложением 21 000 000 единиц. |
| **Frozen Balance** | Временный 72-часовой буфер для квалифицируемого Спонсорского бонуса сверх оставшегося Лимита вознаграждений протокола. |
| **GovToken** | Токен управления стандарта ERC20Votes с фиксированным предложением. |
| **Matching Bonus** | Условное вознаграждение до трёх квалифицируемых уровней. |
| **Пропущенное вознаграждение** | Активность, не зачисленная из-за невыполнения применимых условий участия. |
| **NFTM** | Внутренний счётчик Майнинга, используемый в расчёте Фарминга. |
| **Партнёрская сеть** | Структура, управляемая смарт-контрактом, определяющая размещение и право на вознаграждения. |
| **Глубина партнёрской сети** | Максимальная глубина сети, включаемая в расчёты квалифицируемого распределения. |
| **Лимит вознаграждений протокола** | Максимальные совокупные квалифицируемые вознаграждения, зачисляемые в течение цикла NFT; он-чейн термин: *Income Limit*. |
| **Спонсорский бонус** | Условное вознаграждение от квалифицируемой прямой покупки NFT. |
| **Распределение по дереву** | Поуровневый расчёт партнёрского вознаграждения в пределах допустимой глубины сети. |
