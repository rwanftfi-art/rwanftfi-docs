Единый источник истины для терминов, используемых в документации RWANFTFI.

## Протокол

| Термин | Определение |
|---|---|
| **Накопительный баланс** | Ограниченный внутренний баланс, получающий настроенную долю квалифицируемых партнёрских вознаграждений. Неиспользованные средства могут быть перераспределены после окончания срока жизни баланса — сейчас 180 дней (временно продлён голосованием DAO). |
| **Auto-Sell** | Плановая обработка оставшегося DA за четыре протокольных периода. |
| **Autobuy (автопокупка)** | Автоматическое продление подходящего NFT при исчерпании его Лимита вознаграждений протокола. |
| **DA** | Непередаваемый служебный токен протокола стандарта BEP-20 с максимальным предложением 21 000 000 единиц. |
| **Frozen Balance** | Временный 72-часовой буфер для квалифицируемого Спонсорского бонуса сверх оставшегося Лимита вознаграждений протокола. |
| **GovToken** | Токен управления стандарта ERC20Votes с фиксированным предложением. |
| **Income Limit** | Он-чейн термин для Лимита вознаграждений протокола. |
| **NFTM** | Внутренний счётчик Майнинга, используемый в расчёте Фарминга. |
| **Фаза 2** | Конфигурация протокола, активированная голосованием DAO в июне 2026 года: текущее распределение покупок NFT и продажи Infinity (L10). |
| **Лимит вознаграждений протокола** | Максимальные совокупные квалифицируемые вознаграждения, зачисляемые в течение цикла NFT; он-чейн термин: *Income Limit*. |

## Партнёрская программа

| Термин | Определение |
|---|---|
| **Business Sale** | Авторизованная DAO передача полной партнёрской структуры другому пользователю; отключена голосованием DAO с июня 2026 года. |
| **Подарочный NFT** | NFT, который нельзя купить или продать; выдаётся по акциям и программам. Имеет собственное место и Лимит вознаграждений протокола, вознаграждения по нему делятся 50/50 между Обычным и Накопительным балансом, и он открывает FinFlow. |
| **Matching Bonus** | Условное вознаграждение до трёх квалифицируемых уровней. |
| **Пропущенное вознаграждение** | Активность, не зачисленная из-за невыполнения применимых условий участия. |
| **Партнёрская сеть** | Структура, управляемая смарт-контрактом, определяющая размещение и право на вознаграждения. |
| **Глубина партнёрской сети** | Максимальная глубина сети, включаемая в расчёты квалифицируемого распределения. |
| **Спонсорский бонус** | Условное вознаграждение от квалифицируемой прямой покупки NFT. |
| **Распределение по дереву** | Поуровневый расчёт партнёрского вознаграждения в пределах допустимой глубины сети. |

## FinPro

| Термин | Определение |
|---|---|
| **Claim Spot** | Этап предстарта FinPro Marketing, на котором участник занимает место в структуре и получает реферальную ссылку. |
| **Compound** | Реинвестирование начислений в тело позиции, которое увеличивает абсолютную сумму будущих начислений. |
| **Direct Sale** | В FinPro Marketing — 5% с каждого начисления по позициям лично приглашённого партнёра, на каком бы уровне он ни был размещён. |
| **Earn cap (потолок начислений)** | Потолок выплат по позиции FinPro; для FinFlow — 200% от начального тела, само тело входит в этот потолок. |
| **FinCore** | Следующий продукт FinPro и первый с FinPro Marketing; его параметры публикуются до запуска. |
| **FinFlow** | Первый продукт FinPro, работает с 8 июля 2026 года: позиции в маркет-нейтральной стратегии. |
| **Лимит FinFlow** | Максимальная сумма открытых позиций FinFlow для NFT; базовый лимит равен Лимиту вознаграждений протокола. |
| **FinFlow NFT** | Непередаваемый NFT, представляющий позицию FinFlow. Открытие позиции не является депозитом. |
| **FinPro** | Линейка финансовых продуктов экосистемы на rwafinpro.com, которые пополняются напрямую с EVM-кошелька пользователя. |
| **FinPro Marketing** | Отдельная партнёрская программа для продуктов FinPro с собственной структурой: Direct Sale и 20 уровней, 100% зачисляется на маркетинговый баланс. |
| **Начисления по позициям** | То, что начисляется по позициям FinPro; начисления не гарантированы. |
| **Баланс позиций** | Сумма всех открытых позиций FinPro, включая пополнения и реинвестированные суммы; открывает уровни FinPro Marketing. |
| **Refund (возврат)** | Для FinFlow: после того как держатель получил и вывел 50% начальной суммы, позицию можно закрыть с возвратом остатка до 100% начальной суммы. |

## Безопасность и сервисы

| Термин | Определение |
|---|---|
| **AML Checker** | Платная проверка риска адреса кошелька по 19 блокчейнам и 14 стейблкоинам в приложении. |
| **Мост** | Управляемый сервис кроссчейн-депозитов на bridge.rwanftfi.com для 14 сетей. |
| **Secret Code** | Случайное слово, которое генерируется вместе с финансовым паролем; обязателен для любого запроса в поддержку по безопасности. |
